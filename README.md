# Курс ML-инженера по roadmap.sh — оглавление

Полный план курса (94 урока, 52 недели × 9 ч): [План курса.md](План%20курса.md).

**Как устроена папка курса:** каждая часть лежит в одноимённой папке — `Модуль NN. …/Урок NN. …/`. В папке урока:
- `Урок NN. ….md` — урок со ссылками на материалы;
- `Задания.md` — упражнения 🟢 / 🟡 / 🔴;
- `код/` — проверенный код урока (`.py` + тесты pytest);
- `решения/` — сюда кладёшь свои решения и пишешь «проверь урок N».

Окружение — [pyproject.toml](pyproject.toml) (PyTorch 2.14 + cu126 под GTX 1050 Ti), настройка — в уроке 2.

**Статус:** готовы модули 0–5 (уроки 1–35). Модули 6–11 будут добавляться по одному в том же формате.

## Команды

- «Урок N» / «Дальше» — следующий урок (или модуль) в этом же формате.
- «проверь урок N» — разбор решения из папки `решения/` урока.
- «проверь мини-проект N», «проверь повторение N».
