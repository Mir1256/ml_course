Решения клади в папку [решения/](решения/) рядом с этим файлом и пиши «проверь урок 26».

**🟢 Базовое — «Безопасное чтение CSV»** (`safe_csv.py` + `test_safe_csv.py`)
Тебе прислали CSV разметки от подрядчика: разделитель `;`, кодировка cp1251, десятичная запятая, id с ведущими нулями, даты в формате `31.10.2026 14:05`, в комментариях встречаются `;` в кавычках.
1. Сгенерируй такой файл сам (с подвохами) и напиши `read_vendor_csv(path) -> DataFrame` с правильными `sep`, `encoding`, `decimal`, `dtype`, `parse_dates` (с явным `format`) и `quotechar`.
2. Проверка схемы после чтения: ожидаемые колонки и типы, иначе понятная ошибка.
3. Сохрани в Parquet и покажи, что повторное чтение даёт идентичный DataFrame (`pd.testing.assert_frame_equal`).

**🟡 Среднее — «Полигоны и RLE»** (`masks_formats.py` + `test_masks_formats.py`)
1. Реализуй кодирование и декодирование бинарной маски в несжатый RLE COCO (серии по столбцам, **column-major**, начиная с длины серии нулей). Сверь с `pycocotools.mask.encode` / `decode` (`pip install pycocotools`).
2. Перевод полигона в маску (растеризация через `matplotlib.path.Path.contains_points` по сетке центров пикселей) и маски в полигон (`skimage.measure.find_contours` или свой обход контура).
3. Перевод полигона COCO (пиксели) в формат YOLO-сегментации (нормированные координаты).
4. Тесты: round-trip маска → RLE → маска точный; маска → полигон → маска даёт IoU > 0,95 с исходной для выпуклых фигур. Объясни, почему для невыпуклых и тонких объектов IoU хуже.

**🔴 Со звёздочкой — «Шарды для обучения»** (`shards.py` + `test_shards.py` + замер)
Миллионы мелких файлов — медленно и неудобно (лимиты файловой системы, случайное чтение с диска).
1. Упакуй 5000 картинок (кропы `load_sample_images`, JPEG) с YOLO-разметкой в tar-шарды по 500 примеров в формате WebDataset: файлы `00042.jpg`, `00042.txt`, `00042.json` с одним ключом.
2. Напиши итератор чтения шардов (`tarfile`), который отдаёт `(image, boxes)` и умеет перемешивать порядок шардов и примеров внутри буфера.
3. Сравни время полного прохода: (а) отдельные файлы в папке; (б) tar-шарды. Объясни разницу на HDD и SSD.
4. Тест: множество ключей после распаковки совпадает с исходным, разметка цела.
