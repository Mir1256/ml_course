# Задания к уроку 2. Рабочее окружение

Решения клади в папку [решения/](решения/) рядом с этим файлом и пиши «проверь урок 2».

**🟢 Базовое — «Окружение работает»** (`env_report.txt`)
1. Поставь драйвер 580, uv и окружение курса по разделу 4 урока.
2. Запусти `env_check.py` и `pytest` по папке `код/`. Сохрани оба вывода в `env_report.txt`, вместе с выводом `nvidia-smi`.
3. Открой в VS Code новый ноутбук `решения/check.ipynb`. В первой ячейке выведи `sys.executable`, `torch.__version__` и результат `torch.ones(3, device="cuda") * 2`.

Готово, если: в отчёте есть `sm_61` в списке архитектур, matmul совпадает с CPU, все тесты зелёные (GPU-тест не пропущен), а ноутбук и скрипт используют один и тот же `.venv`.

**🟡 Среднее — «Где GPU действительно быстрее»** (`benchmark.py` + `benchmark.png`)
Напиши бенчмарк матричного умножения для размеров $n \in \{64, 128, 256, 512, 1024, 2048, 4096\}$:
- три варианта: NumPy на CPU, torch FP32 на GPU, torch FP16 на GPU;
- корректный замер: прогрев, `torch.cuda.synchronize()`, медиана по 10 повторам;
- **отдельно** измерь время копирования матриц CPU → GPU и обратно;
- график GFLOPS от $n$ (логарифмическая ось X) и второй график «время с учётом копирования».

Ответь в комментарии в конце файла (3–5 предложений): при каком $n$ GPU начинает выигрывать с учётом копирования, во сколько раз FP16 медленнее FP32 на твоей карте и почему.

**🔴 Со звёздочкой — «Воспроизводимость»** (`seed.py` + `test_seed.py`)
1. Напиши `seed_everything(seed: int, deterministic: bool = True)`: фиксирует `random`, `numpy`, `torch` (CPU и CUDA), а при `deterministic=True` включает `torch.use_deterministic_algorithms(True)`, `torch.backends.cudnn.benchmark = False` и нужную переменную окружения для cuBLAS. Какую именно, найди в документации PyTorch «Reproducibility».
2. Тест: маленький MLP (2 слоя) обучается 50 шагов на случайных данных дважды с одним сидом. Веса должны совпасть **бит-в-бит** на CPU и на GPU.
3. Тест «наоборот»: найди операцию, которая на GPU недетерминирована (подсказка: `index_add_` или `scatter_add_` с повторяющимися индексами в FP32), и покажи, что при `deterministic=True` PyTorch либо делает её детерминированной, либо бросает ошибку.
4. В docstring объясни, почему на GPU результаты могут отличаться между запусками (порядок суммирования float, атомарные операции), и почему результаты CPU и GPU в общем случае не совпадут бит-в-бит даже с одним сидом.
