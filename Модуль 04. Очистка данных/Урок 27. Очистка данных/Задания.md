Решения клади в папку [решения/](решения/) рядом с этим файлом и пиши «проверь урок 27».

**🟢 Базовое — «Аудит папки картинок»** (`audit_images.py` + `test_audit_images.py`)
Напиши `audit_folder(path) -> pd.DataFrame` по всем картинкам папки (рекурсивно):
1. Колонки: путь, размер файла, формат, ширина, высота, режим (RGB/L/RGBA/CMYK), EXIF-ориентация, читается ли (`verify` + `load`), sha256, dHash.
2. Флаги проблем: битый файл, картинка меньше 32 px по стороне, не RGB (CMYK, RGBA, палитра), точный дубликат (sha256), почти-дубликат (dHash ≤ 8, векторизованная матрица Хэмминга).
3. Тесты на временной папке с намеренно созданными проблемами: обрезанный JPEG, CMYK-картинка, PNG с альфа-каналом, копия и пережатая копия.

**🟡 Среднее — «Утечка, которую не видно»** (`leak_hunt.py`)
Сгенерируй табличный датасет «качество детекции по кадрам» с ловушками и найди их:
1. Признак `n_boxes_labeled` (число размеченных рамок) при цели «есть ли на кадре человек» — target leakage.
2. Признак `frame_id`, монотонно растущий во времени, при сдвиге распределения во времени — утечка из будущего при случайном сплите. Сравни случайный сплит с временным (`TimeSeriesSplit`).
3. Нормализация по всему датасету до сплита — покажи на маленькой выборке, что разница в метрике есть, и объясни её величину.
Для каждой утечки: (а) как её поймать (что в метриках или важностях признаков выдаёт её); (б) как исправить; (в) метрика до и после исправления.

**🔴 Со звёздочкой — «Confident learning для детекции»** (`noisy_boxes.py` + отчёт)
1. Возьми синтетическую детекцию из урока 18 🔴 (или синтетику с рамками) и внеси три вида шума: пропущенные объекты (удалить 10% рамок), лишние рамки (+5% на фоне), неверный класс (7%).
2. Для «неверного класса» примени подход из урока: классификатор кропов + вероятности вне фолда + пороги по классам.
3. Для «пропущенных объектов» найди уверенные предсказания модели, не сопоставленные ни с одной истинной рамкой (IoU < 0,3), — кандидаты в пропуски разметки.
4. Для каждого типа шума посчитай precision и recall поиска и сделай вывод: сколько картинок нужно перепроверить вручную, чтобы найти 80% ошибок, по сравнению со случайной проверкой.
