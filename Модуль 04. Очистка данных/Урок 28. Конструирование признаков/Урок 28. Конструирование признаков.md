## 1. Зачем это нужно

Модель видит только те признаки, что ей дали. Хорошо составленный признак может дать больше, чем смена алгоритма:
- **час съёмки** как число 0–23 говорит модели, что 23:00 и 01:00 далеки друг от друга, а это неправда;
- **площадь рамки** как есть — длинный правый хвост (урок 16), а её логарифм почти нормален;
- **камера** — категория из 50 значений: как подать её линейной модели, чтобы не переобучиться?

В CV до 2012 года признаки картинок писали руками: **HOG** (детектор пешеходов Dalal & Triggs, 2005), SIFT, цветовые гистограммы. Сейчас их учат нейросети, но ручные признаки:
- объясняют, что именно выучивают первые слои CNN;
- полезны для быстрых бейзлайнов;
- работают там, где мало данных;
- служат для дешёвых проверок качества данных (урок 27).

## 2. Интуиция

- **Кодирование категорий.** One-hot — «по столбцу на значение»: честно, но признаков много. Target encoding — заменить категорию средним значением цели по ней: компактно, но при неаккуратном подсчёте модель «подсматривает» свою же метку.
- **Преобразования числовых признаков.** Логарифм превращает мультипликативные эффекты в аддитивные и приручает хвосты. Циклические признаки (час, день недели, угол) кладут на окружность через $(\sin, \cos)$.
- **Доменные признаки** берутся из знания предметной области: у рамки — соотношение сторон, положение по вертикали (объекты внизу кадра ближе к камере), расстояние до края (у края объект часто обрезан).
- **HOG:** форму объекта описывает распределение **направлений краёв** по участкам картинки. Абсолютная яркость и цвет важны меньше. Поэтому HOG считает в каждой маленькой клетке гистограмму направлений градиентов, а потом нормирует её по соседству, чтобы убрать влияние освещения.
- **Цветовая гистограмма** — сколько пикселей каждого цвета, без учёта того, **где** они. Глобальный «отпечаток» сцены: инвариантен к перестановке пикселей, отражению, поворотам.

## 3. Математика

### 3.1. HOG по шагам

1. **Градиенты** центральными разностями (урок 8): $g_x = I(x+1, y) - I(x-1, y)$, $g_y = I(x, y+1) - I(x, y-1)$; модуль $m = \sqrt{g_x^2 + g_y^2}$, направление $\theta = \operatorname{atan2}(g_y, g_x) \bmod 180°$. «Беззнаковое» направление: переход светлое→тёмное и тёмное→светлое — одна и та же граница.
2. **Гистограммы клеток:** картинка делится на клетки $8 \times 8$. В каждой — гистограмма из 9 корзин по $20°$, каждый пиксель голосует за корзину своего направления **с весом $m$**. Слабые градиенты (шум) почти не голосуют.
3. **Нормировка по блокам** $2 \times 2$ клетки: вектор блока $v$ (36 чисел) делится на $\sqrt{\|v\|^2 + \varepsilon^2}$, значения обрезаются на 0,2 и снова нормируются (L2-Hys). Если умножить картинку на $a$ (контраст) и прибавить $b$ (яркость), градиенты умножатся на $a$ и не зависят от $b$, а нормировка убирает $a$. Значит, **HOG инвариантен к линейным изменениям освещения**. Это проверяет тест `test_hog_brightness_invariance`. Обрезание на 0,2 не даёт одному очень сильному краю задавить остальные.
4. **Итог** — конкатенация блоков. Для $32 \times 32$: клеток $4 \times 4$, блоков $3 \times 3$ (со сдвигом в одну клетку), $9 \cdot 36 = 324$ числа.

Почему HOG устойчивее пикселей к сдвигу: при сдвиге на 2 пикселя почти каждый пиксельный признак меняется полностью, а гистограмма клетки $8 \times 8$ меняется лишь на краях клетки — большая часть пикселей остаётся в той же клетке.

### 3.2. Target encoding и его байесовское сглаживание

Наивно: $\text{TE}(c) = \bar y_c$ — среднее цели по категории $c$. Две проблемы.
- **Утечка.** Для объекта $i$ в среднее входит его собственная метка $y_i$. У редкой категории с одним объектом $\text{TE} = y_i$ — признак просто равен ответу. Лечение: **кросс-фиттинг** — кодировку для объектов фолда считают по остальным фолдам (как вероятности вне фолда в уроке 27). `sklearn.preprocessing.TargetEncoder` делает это внутри `fit_transform`.
- **Шум у редких категорий.** Среднее по 2 объектам ненадёжно. Сглаживание — это апостериорное среднее с prior из урока 13:

$$\text{TE}(c) = \frac{n_c\,\bar y_c + m\,\bar y}{n_c + m},$$

где $\bar y$ — общее среднее, $m$ — «сила prior» (псевдо-наблюдения). Для бинарной цели это ровно среднее Beta-апостериорного распределения с prior Beta$(m\bar y, m(1 - \bar y))$. При $n_c \ll m$ кодировка ≈ общему среднему, при $n_c \gg m$ — ≈ среднему категории.

### 3.3. Циклические признаки

Час $h$ кладём на единичную окружность: $(\sin\frac{2\pi h}{24}, \cos\frac{2\pi h}{24})$. Евклидово расстояние между часами $h_1, h_2$ — хорда:

$$d = 2\sin\frac{\pi|h_1 - h_2|}{24},$$

и оно зависит от «кругового» расстояния. Для 23:00 и 01:00 это $2\sin(\pi/12) \approx 0{,}518$ — так же, как для 10:00 и 12:00. Самые далёкие — противоположные часы ($d = 2$).

### 3.4. One-hot и ловушка фиктивных переменных

$K$ столбцов one-hot в сумме дают 1 в каждой строке — это столбец единиц. Вместе со свободным членом линейной модели они **линейно зависимы** (урок 5): $X^\top X$ вырождена. Решения: убрать один столбец (`drop="first"`) или использовать регуляризацию (Ridge — урок 40). Редкие категории (меньше `min_frequency` объектов) объединяют в одну «прочие», а неизвестные на инференсе (новая камера) — туда же.

## 4. Реализация с нуля

Файл: [код/hog.py](код/hog.py). Гистограммы клеток без циклов по пикселям — через `bincount` с весами (урок 21):

```python
def hog(img, orientations=9, cell=8, block=2, eps=1e-5):
    img = img.astype(float)
    gx, gy = gradients(img)
    mag = np.hypot(gx, gy)
    ang = np.rad2deg(np.arctan2(gy, gx)) % 180
    n_cy, n_cx = img.shape[0] // cell, img.shape[1] // cell
    bins = np.minimum((ang / (180 / orientations)).astype(int), orientations - 1)

    ys, xs = np.mgrid[: n_cy * cell, : n_cx * cell]
    idx = ((ys // cell) * n_cx + xs // cell) * orientations + bins[: n_cy * cell, : n_cx * cell]
    hist = np.bincount(idx.ravel(), weights=mag[: n_cy * cell, : n_cx * cell].ravel(),
                       minlength=n_cy * n_cx * orientations).reshape(n_cy, n_cx, orientations) / cell**2

    blocks = []
    for by in range(n_cy - block + 1):
        for bx in range(n_cx - block + 1):
            v = hist[by:by + block, bx:bx + block].ravel()
            v = v / np.sqrt(np.sum(v**2) + eps**2)
            v = np.minimum(v, 0.2)
            blocks.append(v / np.sqrt(np.sum(v**2) + eps**2))
    return np.concatenate(blocks)
```

## 6. Типичные ошибки и как их отлаживать

| Ошибка | Последствие | Как правильно |
|---|---|---|
| Target encoding по всем данным | Утечка: «модель отлично работает» на валидации | `TargetEncoder` (кросс-фиттинг) внутри Pipeline + сглаживание |
| Час, день недели, угол как число | Модель считает 23 и 0 далёкими | $(\sin, \cos)$ |
| One-hot без `handle_unknown` | Падение на новой категории в продакшене | `handle_unknown="infrequent_if_exist"` или `"ignore"` |
| One-hot всех $K$ столбцов + свободный член в линейной модели без регуляризации | Вырожденная $X^\top X$ (урок 5) | `drop="first"` или регуляризация |
| Логарифм от нуля | `-inf` | `np.log1p` или сдвиг |
| HOG на картинке, чьи стороны не кратны клетке | Края картинки молча отбрасываются | Ресайз к кратному размеру, как в коде (8×8 → 32×32) |
| Признаки, посчитанные с использованием цели или будущего | Target leakage (урок 27) | Для каждого признака: «будет ли он известен при предсказании?» |

## Ответы на вопросы для самопроверки

1. (1) Градиенты и их направления; (2) гистограммы направлений в клетках, взвешенные модулем градиента; (3) нормировка векторов блоков из соседних клеток (L2-Hys). Яркость $b$ не влияет на разности, контраст $a$ умножает все градиенты блока и сокращается нормировкой.
2. При небольшом сдвиге пиксели в основном остаются в своих клетках, и гистограммы почти не меняются. Пиксельный признак «значение в точке $(i, j)$» меняется полностью.
3. В среднее по категории входит собственная метка объекта, и у редких категорий признак почти равен ответу. Кросс-фиттинг считает кодировку для объектов фолда только по остальным фолдам — своя метка не используется.
4. $\text{TE}(c) = \frac{n_c\bar y_c + m\bar y}{n_c + m}$ — апостериорное среднее Beta-Bernoulli с prior Beta$(m\bar y, m(1-\bar y))$: $m$ псевдо-наблюдений с общим средним плюс $n_c$ настоящих.
5. Чтобы соседние по кругу значения были близки. $2\sin(\pi \cdot 2/24) = 2\sin 15° \approx 0{,}518$.
6. Сумма столбцов one-hot = столбец единиц, линейно зависимый со свободным членом → $X^\top X$ вырождена. Убрать один столбец или регуляризовать.
7. Ширина, высота, $\log$ площади, соотношение сторон, относительное положение центра (особенно по вертикали), расстояние до края кадра (признак обрезанности), доля площади кадра; при нескольких объектах — число соседей и максимальное IoU с ними (перекрытие).
