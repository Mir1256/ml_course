**🟢 Базовое — «Признаки из разметки и метаданных»** (`ann_features.py` + `test_ann_features.py`)
На синтетических аннотациях из урока 16 (`make_annotations`) построй функцией (method chaining, урок 22):
1. Геометрию рамки: `log_area`, `aspect`, `rel_cx`, `rel_cy`, `border_dist`, флаг «касается края».
2. Контекст картинки: число объектов на картинке, доля объектов того же класса, максимальное IoU с другими рамками той же картинки (`groupby` + векторизованная матрица IoU из урока 21).
3. Время: час съёмки (сгенерируй его) в $(\sin, \cos)$, флаг «ночь».
4. Тесты на маленьком ручном примере для каждой группы признаков.

**🟡 Среднее — «HOG + цвет: классификатор без нейросетей»** (`hog_classifier.py` + отчёт)
Данные: Fashion-MNIST (как в мини-проекте 1) или CIFAR-10 (цвет важен).
1. Признаки: (а) сырые пиксели; (б) HOG (свой, из урока); (в) цветовая гистограмма 8×8×8 (для CIFAR-10); (г) HOG + цвет.
2. Логистическая регрессия на каждом наборе признаков в одном `Pipeline` со `StandardScaler`. Сравни accuracy и устойчивость к сдвигу на 2 px и к изменению яркости ×0,7.
3. Подбери `cell` (4, 6, 8) и `orientations` (6, 9, 12) по кросс-валидации. Объясни компромисс: мелкие клетки — больше деталей и признаков, но меньше устойчивости.
4. Визуализируй HOG (`skimage.feature.hog(..., visualize=True)`) для двух классов, которые модель путает чаще всего.

**🔴 Со звёздочкой — «Свой TargetEncoder»** (`target_encoder.py` + `test_target_encoder.py`)
Реализуй совместимый со scikit-learn класс (`BaseEstimator`, `TransformerMixin`):
1. `fit` запоминает сглаженные средние по категориям (формула 3.2, параметр `m`); `transform` применяет их (неизвестная категория → общее среднее).
2. `fit_transform` делает **кросс-фиттинг** по `KFold`: для объектов фолда — кодировка, обученная на остальных фолдах. Объясни в docstring, почему `fit_transform` ≠ `fit().transform()` и почему это правильно.
3. Тесты: на данных из урока (2000 шумовых камер) cross-val accuracy ≈ 0,5; при `m → ∞` кодировка = общему среднему; совместимость с `Pipeline` и `cross_val_score`.
4. Сравни со `sklearn.preprocessing.TargetEncoder` по качеству на реальном датасете с категориями (например, `fetch_openml("adult")` — колонки `occupation`, `native-country`).
