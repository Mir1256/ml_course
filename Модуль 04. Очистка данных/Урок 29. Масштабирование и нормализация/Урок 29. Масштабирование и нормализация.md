## 1. Зачем это нужно

В каждом CV-пайплайне стоит строка `Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225])`. Это масштабирование признаков (пикселей) статистиками ImageNet. Если забыть её на инференсе или поставить другие числа, предобученный бэкбон получит входы не того масштаба, и качество упадёт. Это training-serving skew из урока 1.

В табличных задачах: на датасете вин из кода урока KNN без масштабирования даёт 69%, со стандартизацией — 95%. Градиентный спуск на сырых признаках не сошёлся за 200 000 шагов, на стандартизованных — за 499. А дереву решений всё равно.

## 2. Интуиция

- **Расстояния.** KNN, k-means, SVM с RBF-ядром, PCA сравнивают объекты по евклидову расстоянию. Если один признак измеряется в тысячах (пролин в вине — 278…1680), а другой в долях (0,13…0,66), расстояние определяется практически только первым. Масштабирование даёт признакам «равный голос».
- **Градиентный спуск.** Признаки разного масштаба делают долину функции потерь вытянутой. Learning rate ограничен самым крутым направлением, а по пологому спуск ползёт (урок 6).
- **Деревья** сравнивают признак с порогом: «пролин > 755». Любое монотонное преобразование признака (масштаб, сдвиг, логарифм) просто сдвигает порог. Разбиения, а значит и предсказания, те же.
- **Выбросы.** Min-max масштабирует по крайним значениям: один выброс сожмёт все нормальные значения в узкую полосу. Robust-масштабирование (медиана и IQR) выбросов почти не замечает.

## 3. Математика

### 3.1. Основные преобразования

| Скейлер | Формула | Свойства |
|---|---|---|
| Standard | $z = (x - \mu)/\sigma$ | Среднее 0, дисперсия 1; чувствителен к выбросам |
| Min-max | $x' = (x - \min)/(\max - \min)$ | Ровно $[0, 1]$ на train; ломается от одного выброса |
| Robust | $x' = (x - \text{median})/\text{IQR}$ | Устойчив к выбросам (точка разрушения 25%, урок 16) |
| Max-abs | $x' = x/\max|x|$ | Сохраняет нули — для разреженных данных |
| Квантильный / степенной | Ранги → равномерное или нормальное; Box-Cox, Yeo-Johnson | Делает распределение близким к нормальному, но нелинейно |

**Статистики считаются только по train** (урок 27): $\mu$, $\sigma$, min, max, медиана — это параметры, обученные на данных. На test применяются **те же** числа, поэтому значения на test могут выходить за $[0, 1]$ или иметь ненулевое среднее, и это нормально.

### 3.2. Масштабирование и обусловленность

Для линейной регрессии гессиан MSE — $H = \frac{2}{n}X^\top X$ (урок 10). Если столбец $j$ умножить на $s_j$, то $X \to XS$, $S = \operatorname{diag}(s)$, и $H \to SHS$. При огромном разбросе масштабов $s_j$ собственные значения $H$ разнесены на порядки, число обусловленности $\kappa$ огромно, и GD требует $\sim\kappa$ шагов (урок 6, 3.6). Стандартизация приводит диагональ $H$ к одинаковым значениям (корреляционная матрица). На вине $\kappa$ упало с $1{,}2 \cdot 10^7$ до 46.

Стандартизация не делает $\kappa = 1$: остаётся корреляция признаков. Полностью её убирает whitening — $\Sigma^{-1/2}$ (урок 14). Адаптивные оптимизаторы (Adam, урок 66) делают «масштабирование» по каждому параметру на лету, BatchNorm — по активациям внутри сети.

### 3.3. Почему деревьям всё равно

Разбиение дерева — «$x_j \le t$». Для любой строго возрастающей $f$: $x_j \le t \iff f(x_j) \le f(t)$. Множество возможных разбиений обучающей выборки не меняется, и критерий качества (урок 42) для них тот же. Значит, дерево с порогом $f(t)$ на преобразованных данных даёт ровно те же предсказания. Масштабирование деревьям и бустингу не нужно. Но и не вредит, а в общем пайплайне с линейными моделями его часто оставляют.

### 3.4. Нормализация картинок

Для изображений «признаки» — пиксели, а статистики считают **по каналам** по всему датасету (урок 3):

$$x'_{c,h,w} = \frac{x_{c,h,w}/255 - \mu_c}{\sigma_c}.$$

- **Предобученная модель:** берём статистики **её** обучающего датасета (ImageNet — `0.485, 0.456, 0.406` / `0.229, 0.224, 0.225`), а не своего. Бэкбон «привык» именно к ним.
- **С нуля:** свои статистики по train (мини-проект 2).
- **Внимание:** часть моделей (например, YOLO в Ultralytics) ждёт просто деление на 255 без вычитания среднего. Правильная нормализация — часть контракта модели, её нужно смотреть в документации или коде.

## 4. Реализация с нуля

Файл: [код/scalers.py](код/scalers.py) — скейлеры в стиле sklearn, с защитой от деления на ноль на константных признаках:

```python
class RobustScalerNP:
    def fit(self, X):
        self.center_ = np.median(X, axis=0)
        q75, q25 = np.percentile(X, [75, 25], axis=0)
        iqr = q75 - q25
        self.scale_ = np.where(iqr == 0, 1.0, iqr)
        return self

    def transform(self, X):
        return (X - self.center_) / self.scale_


def normalize_images(batch_nchw, mean=(0.485, 0.456, 0.406), std=(0.229, 0.224, 0.225)):
    m = np.asarray(mean, np.float32)[None, :, None, None]
    s = np.asarray(std, np.float32)[None, :, None, None]
    return (batch_nchw - m) / s
```

## 6. Типичные ошибки и как их отлаживать

| Ошибка | Последствие | Как правильно |
|---|---|---|
| `fit` скейлера на всём датасете | Утечка (урок 27) | Скейлер внутри `Pipeline` |
| `fit_transform` на test | Test масштабирован своими статистиками — модель видит «другие» данные | На test только `transform` |
| Нормализация ImageNet для модели, которая её не ждёт (или наоборот) | Тихое падение качества | Смотреть контракт модели; тест «одинаковый вход → одинаковый выход» train против serve |
| Min-max при выбросах | Признак схлопывается | Robust или клиппинг перед масштабированием |
| Масштабирование one-hot и бинарных признаков стандартизацией | Не ошибка, но теряется интерпретация 0/1 | `ColumnTransformer`: масштабировать только числовые |
| Нормализация по каждой картинке отдельно (per-image) | Теряется информация об абсолютной яркости (ночь/день) | Осознанный выбор: per-dataset по умолчанию |
| Скейлер не сохранён вместе с моделью | На инференсе не та нормализация | Сохранять `Pipeline` целиком (урок 35), статистики — в артефакт (урок 1) |

## Ответы на вопросы для самопроверки

1. Нужно: моделям на расстояниях (KNN, k-means, SVM с RBF, PCA), на градиентном спуске (линейные модели, нейросети), с регуляризацией (штраф $\|w\|^2$ зависит от масштаба признаков). Не нужно: деревьям, случайному лесу, градиентному бустингу.
2. Разбиение $x \le t$ для строго возрастающей $f$ эквивалентно $f(x) \le f(t)$: разбиение обучающих объектов то же, значения критерия те же, предсказания совпадают.
3. Масштаб столбцов $S$ переводит гессиан в $SHS$; разные масштабы разносят собственные значения, $\kappa$ растёт, и GD требует $\sim\kappa$ шагов. Стандартизация выравнивает диагональ и уменьшает $\kappa$.
4. Масштаб задаётся экстремальными значениями: один выброс растягивает диапазон, и нормальные значения сжимаются в узкую полосу. Использовать RobustScaler (медиана и IQR) или клиппинг перед масштабированием.
5. Веса модели обучены на входах, нормализованных статистиками ImageNet. Её фильтры «ожидают» этот масштаб и центр. Другие статистики сдвигают распределение входов: это сдвиг, которого модель не видела.
6. Нет. Статистики обучены на train, а новые данные могут выходить за наблюдавшийся диапазон. Важно лишь применять те же параметры. Сильный и частый выход за диапазон — сигнал сдвига распределения.
