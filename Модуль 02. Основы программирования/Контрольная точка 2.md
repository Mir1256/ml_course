## Самопроверка (30 минут)

1. Напиши без циклов функцию, которая для массива рамок `(N, 4)` и массива меток `(N,)` возвращает медианную площадь рамок по классам.
2. Найди ошибку:
   ```python
   class DS:
       def __init__(self, files, aug=[]): self.files, self.aug = files, aug
       def __getitem__(self, i): x = load(self.files[i]); [a(x) for a in self.aug]; return x
   ```
3. Почему `torch.from_numpy(img[:, ::-1])` падает и как это исправить?
4. `df.groupby("category").score.mean()` по колонке типа `category` выводит строки с `NaN` для классов, которых нет в данных. Почему и как убрать?
5. В отчёте написано «у класса A меньше разброс уверенности — смотрите, усы короче». В чём ошибка?

<details>
<summary>Ответы</summary>

1. Например, через pandas: `pd.Series(area).groupby(labels).median()`. На чистом NumPy — сортировка по `(label, area)` через `np.lexsort` и середина каждой группы, как `group_median` из урока 22.
2. Три проблемы: (а) изменяемый аргумент по умолчанию `aug=[]` общий для всех экземпляров; (б) результаты аугментаций выбрасываются: `[a(x) for a in self.aug]` не присваивает `x`, а если аугментации мутируют `x` на месте — это другой баг (изменение исходных данных); (в) нет `__len__`, и `DataLoader` не сможет с ним работать (и нет `IndexError` на границе). Правильно: `aug=None`, `for a in self.aug: x = a(x)`, `__len__`.
3. Срез с шагом −1 — view с отрицательным stride, а тензоры PyTorch такие не поддерживают. `img[:, ::-1].copy()` или `np.ascontiguousarray(...)`.
4. По категориальной колонке `groupby` с `observed=False` выводит все объявленные категории, включая отсутствующие. Нужно `observed=True` (или `remove_unused_categories()`).
5. «Усы» `barplot` по умолчанию — 95%-ДИ **среднего**, их ширина ∝ $s/\sqrt n$. Короче они могут быть просто потому, что объектов класса A больше. Для разброса нужен `errorbar="sd"` или boxplot.
