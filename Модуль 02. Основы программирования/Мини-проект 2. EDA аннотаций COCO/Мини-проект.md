## Цель

Сделать настоящий EDA-отчёт по разметке детекции, какой ты сделал бы перед обучением детектора, и закрепить весь модуль 2: pandas 3, NumPy без циклов, Matplotlib для CV, seaborn. Это первая работа с реальными данными, которые понадобятся снова: в мини-проекте 3 (конвертер форматов) и в capstone.

## Техническое задание

### Часть 1. Загрузка и таблицы (≈ 1 ч)

1. Загрузи `instances_val2017.json` стандартным `json` и построй три DataFrame: `images`, `annotations`, `categories`. Разложи `bbox` в `x, y, w, h`.
2. Соедини их через `merge` с `validate=...`. Добавь колонки: `area_bbox` (`w*h`), `rel_area` (доля площади кадра), `aspect`, `size` (small/medium/large по **полю `area`** из COCO — это площадь маски, а не рамки; сравни с `w*h` и объясни разницу), `cx`, `cy` (центр в долях кадра).
3. Приведи типы: `category`, `float32` для координат. Сохрани в Parquet и сравни размер с JSON.

### Часть 2. Статистика и аудит (≈ 1,5 ч)

1. Распределение классов: топ-10 и антитоп-10, доля самого частого класса. Сколько процентов объектов — `person`?
2. По каждому классу: число объектов, число картинок, медиана и IQR `rel_area`, доля small, доля `iscrowd`.
3. Объектов на картинку: распределение, среднее, максимум. Похоже ли на Пуассона (сравни среднее и дисперсию, урок 15)? Почему нет?
4. **Аудит:** рамки за пределами кадра, вырожденные рамки, точные дубликаты, картинки без аннотаций. Сколько таких в официальной разметке COCO?
5. Посчитай поканальные mean/std пикселей на подвыборке из 500 картинок (`PIL.Image.open` + NumPy, накопление сумм потоково, урок 14 🟡) и сравни со стандартными ImageNet-значениями `(0.485, 0.456, 0.406)` / `(0.229, 0.224, 0.225)`.

### Часть 3. Визуализация (≈ 1,5 ч)

1. Столбцы числа объектов по классам (log-шкала по X, все 80 классов, отсортированы).
2. Распределение `rel_area` в log-шкале с границами small/medium/large; отдельно — для 6 классов (`displot` с `col_wrap`).
3. `hexbin` или 2D-гистограмма `log(w)` против `log(h)` — кластеры форм (это основа для якорей YOLO).
4. Тепловая карта центров объектов `(cx, cy)` для всех объектов и отдельно для `person`, `car`, `sports ball`. Чем они отличаются и почему?
5. Тепловая карта «суперкатегория × размер» с долями.

### Часть 4. Примеры (≈ 1 ч)

1. Сетка 2×5 случайных картинок val2017 с рамками и подписями классов (функция из урока 23).
2. По 4 примера для каждой проблемы из аудита (если они нашлись) и для объектов меньше 8×8 пикселей.
3. 5 картинок с наибольшим числом объектов.

## Подсказки

- `instances_val2017.json` ≈ 25 МБ: грузится в память целиком за секунды. Для train2017 (≈ 450 МБ) понадобился бы потоковый парсер или Parquet-кэш.
- Поле `area` в COCO — площадь **маски сегментации**, она меньше `w*h` для невыпуклых объектов. Пороги small/medium/large в метрике COCO считаются именно по ней (урок 60).
- `iscrowd=1` — «толпа» одной маской. В метрике такие объекты обрабатываются особо, при обучении их обычно игнорируют.
- Для картинок: `PIL.Image.open(path).convert("RGB")` и `np.asarray`. Читать 500 картинок — секунды.
