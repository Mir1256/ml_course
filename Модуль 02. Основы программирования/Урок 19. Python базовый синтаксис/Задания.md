**🟢 Базовое — «Замеры вместо догадок»** (`bench.py`)
С помощью `timeit` сравни и выведи таблицу времени:
1. Сумма миллиона чисел: явный цикл с `+=`, `sum()`, `math.fsum()`.
2. Фильтрация чётных: цикл с `append`, comprehension, `filter` с `lambda`.
3. Проверка принадлежности 10 000 случайных id: в `list` из 100 000 элементов и в `set`.
4. 10 000 раз `pop(0)` из `list` против `popleft()` из `deque`.
В комментарии объясни каждый результат через раздел 3 урока.

**🟡 Среднее — «Парсер разметки YOLO»** (`yolo_io.py` + `test_yolo_io.py`)
Формат YOLO: на каждую картинку — файл `.txt`, в каждой строке `class_id cx cy w h` (нормированные на [0, 1]).
1. `read_yolo_labels(path: Path) -> list[tuple[int, float, float, float, float]]`. Пустой файл → пустой список; лишние пробелы и пустые строки допустимы.
2. Ошибки разметки — своё исключение `LabelFormatError(ValueError)` с номером строки и причиной: не 5 полей, нечисловое значение, координата вне [0, 1], отрицательный id. Генератор `iter_label_errors(folder)` обходит папку (`Path.rglob`) и **лениво** выдаёт ошибки, не падая на первой.
3. `yolo_to_xyxy(labels, img_w, img_h)` — перевод в пиксельные `(x1, y1, x2, y2)`.
4. Тесты с `tmp_path` (фикстура pytest): корректный файл, файл с каждой из 4 ошибок, пустой файл, `\r\n` в конце строк.

**🔴 Со звёздочкой — «Декоратор кэширования с ограничением»** (`cache.py` + `test_cache.py`)
1. Напиши декоратор `@lru_cache_ttl(maxsize, ttl_seconds)`: кэширует результат функции по аргументам, вытесняет давно не используемые записи (LRU) при переполнении и считает записи старше `ttl` недействительными. Используй `collections.OrderedDict` и `functools.wraps`.
2. Поддержи только хэшируемые аргументы. Для нехэшируемых (список) — понятная ошибка `TypeError` с подсказкой.
3. Добавь к обёрнутой функции методы `cache_info()` (hits, misses, size) и `cache_clear()`, как у `functools.lru_cache`.
4. Тесты: LRU-вытеснение, истечение TTL (подмени время через аргумент-часы `clock=time.monotonic`, а не `sleep`), `wraps` сохраняет `__name__` и docstring.
5. В docstring объясни, где кэширование опасно в ML (кэш аугментированных картинок, кэш между процессами `DataLoader`).
