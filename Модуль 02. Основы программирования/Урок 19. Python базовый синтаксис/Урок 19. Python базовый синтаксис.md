## 1. Зачем это нужно

ML-код на Python ломается не на сложных алгоритмах, а на мелочах языка:
- аугментация мутирует **общий** список по умолчанию, и разметка «течёт» между картинками;
- `copy` вместо `deepcopy` в конфиге эксперимента — и второй эксперимент запускается с параметрами первого;
- генератор датасета исчерпан после первой эпохи, и вторая эпоха «обучается» на нуле батчей;
- `except:` без типа глотает `KeyboardInterrupt`, и обучение не остановить.

## 2. Интуиция: модель данных Python для разработчика на C#

| C# | Python | На что обратить внимание |
|---|---|---|
| Переменная хранит значение (value type) или ссылку | **Имя всегда ссылается на объект** | Присваивание никогда не копирует; «значимых типов» нет |
| `int`, `double`, `string` — неизменяемые/значимые | `int`, `float`, `str`, `tuple`, `frozenset` — неизменяемые | Изменяемость ≠ «значимый тип»: `+=` у списка мутирует объект, у кортежа — создаёт новый |
| `List<T>`, `Dictionary<K,V>`, `HashSet<T>` | `list`, `dict`, `set` | `dict` сохраняет порядок вставки (с 3.7) |
| Статическая типизация | Динамическая + аннотации типов (`typing`), проверка — внешними инструментами (mypy, Pylance) | Аннотации не проверяются при выполнении |
| `using` | `with` (контекстный менеджер) | Работает с любым объектом с `__enter__`/`__exit__` |
| LINQ `Select`/`Where` | comprehension, генераторы, `map`/`filter`, `itertools` | Генератор ленив и **одноразов** |
| Целочисленное деление округляет к нулю | `//` округляет **вниз** (к −∞) | `-7 // 2 == -4` |
| Банковское округление — по умолчанию в .NET | `round` — тоже банковское | `round(2.5) == 2` |

## 3. Как это устроено (вместо математики): сложность структур данных

Связь с O-нотацией из урока 11. От выбора структуры зависит, займёт аудит датасета секунды или часы.

| Операция | `list` | `dict` / `set` | `collections.deque` |
|---|---|---|---|
| Доступ по индексу / ключу | $O(1)$ | $O(1)$ в среднем | $O(n)$ |
| `x in ...` | $O(n)$ | $O(1)$ в среднем | $O(n)$ |
| Добавить в конец | $O(1)$ амортизированно | $O(1)$ | $O(1)$ |
| Добавить в начало / `pop(0)` | $O(n)$ | — | $O(1)$ |
| Сортировка | $O(n\log n)$ (Timsort, устойчивая) | — | — |

`dict` и `set` — хэш-таблицы. Ключ должен быть **хэшируемым** (неизменяемым): кортеж можно, список нельзя. Классическая ошибка в ML-скриптах — проверять «есть ли id картинки в списке размеченных» через `list` внутри цикла по 100 000 картинкам. Это $O(n^2)$. Через `set` — $O(n)$.

Почему `list.append` — «$O(1)$ амортизированно»: массив растёт с запасом (в CPython ≈ на 12,5%). Дорогое копирование при переполнении случается всё реже, и средняя стоимость добавления остаётся константой.

@contextmanager
def timer(name, log):
    t0 = time.perf_counter()

        yield
    finally:                                                     # выполнится даже при исключении внутри with

## 5. Сравнение: Python-цикл против встроенных средств

Правило: всё, что можно отдать встроенной функции или C-реализации, работает в разы быстрее Python-цикла. Это прямая подготовка к NumPy (урок 21): там разница — сотни раз.

```python
from timeit import timeit
xs = list(range(1_000_000))
timeit(lambda: sum(xs), number=10)                         # встроенная sum — на C
timeit(lambda: [x for x in xs if x % 2], number=10)        # comprehension — быстрее явного цикла с append
```

## 6. Типичные ошибки и как их отлаживать

| Ошибка | Симптом | Как правильно |
|---|---|---|
| Изменяемый аргумент по умолчанию | Состояние «протекает» между вызовами | `None` по умолчанию, создание внутри |
| `[[0]*n]*m` | Изменение одной строки меняет все | Comprehension |
| Поверхностная копия конфига | Эксперименты влияют друг на друга | `copy.deepcopy` или неизменяемые dataclass (`frozen=True`, урок 20) |
| Повторный проход по генератору | Вторая эпоха — 0 батчей, без ошибки | Список или функция, возвращающая новый генератор |
| `except:` / `except Exception: pass` | Ошибки молча проглатываются; при голом `except:` даже Ctrl+C | Ловить конкретные исключения и логировать |
| Замыкание в цикле (`lambda: i`) | Все функции видят последнее `i` | Аргумент по умолчанию `lambda i=i: i` или `functools.partial` |
| `x in list` в цикле | $O(n^2)$ | `set` / `dict` |
| Склейка путей строками | Ломается между ОС, двойные слэши | `pathlib.Path` |

## Ответы на быструю проверку

1. `[1, 2]` — список по умолчанию общий для всех вызовов.
2. `[[5, 0], [5, 0]]` — обе строки — один и тот же объект.
3. `[0, 1, 2] []` — генератор исчерпан.
4. `-4 1 -3` (`//` вниз, остаток с тем же знаком, что делитель; `int` отбрасывает дробную часть к нулю).
5. `[1, 2, 3, 4]` — `+=` у списка мутирует объект на месте, `y` и `x` — один объект.
6. `(1, 2, 3, 4)` — создаётся **новый** кортеж и имя `t` перепривязывается к нему.
7. `{True: 'c'}` — `True == 1 == 1.0` и у них один хэш, поэтому это один ключ: остаётся первый ключ и последнее значение.
8. `9 ['c', 'b', 'a']`.
9. `0 2 {'a': 1, 'b': 2}`.
10. `[2, 2, 2]` — позднее связывание: `i` берётся из области видимости в момент вызова.
11. `False 2 4` — банковское округление к чётному.
12. `KeyError` (подкласс `LookupError`).

## Ответы на вопросы для самопроверки

1. Имя — ярлык, привязанный к объекту; у самого имени нет типа и «ячейки» под значение. `b = a` привязывает `b` к тому же списку: изменения через `b` видны через `a`.
2. Значение по умолчанию вычисляется один раз при определении функции. Изменяемый объект накапливает состояние между вызовами. Правильно — `None` и создание внутри функции.
3. `copy` копирует только внешний контейнер, вложенные объекты общие; `deepcopy` копирует рекурсивно. Пример: конфиг эксперимента `{"aug": {"flip": True}}`. После `copy` изменение `cfg2["aug"]["flip"]` меняет и первый конфиг.
4. Генератор вычисляет элементы лениво, по одному, и занимает $O(1)$ памяти, но проходится один раз. Хорош для потоковой обработки больших файлов. Опасен, если его неявно нужно пройти дважды (эпохи, `len()`, повторный анализ).
5. $O(n)$, $O(1)$ в среднем, $O(n)$. Замена — `collections.deque.popleft()`, $O(1)$.
6. Замыкание захватывает **переменную**, а не значение. К моменту вызова цикл закончился, и `i == 2`. Решение — `lambda i=i: i`.
7. «Easier to Ask Forgiveness than Permission»: пробуем и обрабатываем исключение вместо предварительных проверок. Нет гонок между проверкой и действием (файл удалили после `exists()`), код короче. Блок `else` выполняется только без исключения и отделяет «рискованную» строку от остального кода.
