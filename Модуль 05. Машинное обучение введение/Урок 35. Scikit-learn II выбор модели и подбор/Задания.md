**🟢 Базовое — «Сравнение моделей на одной CV»** (`compare_models.py`)
На `load_breast_cancer`: логистическая регрессия, KNN, SVM (RBF), дерево, случайный лес — каждая в пайплайне (со скейлером, где нужно) с небольшим `GridSearchCV`.
1. Одна и та же внешняя CV (`RepeatedStratifiedKFold(5, 3)`) для всех моделей; таблица «модель → среднее ± std ROC-AUC».
2. Проверь парным тестом (урок 18; для фолдов — разности оценок по одним и тем же фолдам), значима ли разница между двумя лучшими.
3. Примени правило «одной стандартной ошибки»: выбери самую простую модель в пределах 1 SE от лучшей.

**🟡 Среднее — «Grid против random против halving»** (`search_bench.py` + график)
На `load_digits` с `SVC` (или `HistGradientBoostingClassifier` с 5 гиперпараметрами):
1. При бюджетах 9, 25, 64 запуска сравни grid, random и `HalvingRandomSearchCV` по лучшему CV-score и времени. Повтори 5 раз с разными сидами — разброс.
2. Добавь «бесполезный» гиперпараметр (например, `random_state` модели как ось сетки) и покажи, что grid тратит на него бюджет, а random почти не страдает.
3. Нарисуй карту `cv_results_` (C × gamma → score) для grid и точки random поверх неё.

**🔴 Со звёздочкой — «Optuna и смещение отбора»** (`optuna_nested.py`)
1. Подбери гиперпараметры `HistGradientBoostingClassifier` на `fetch_openml("adult")` (или `load_breast_cancer`) через Optuna (`pip install optuna`, TPE-сэмплер, 50 trials, `pruner` по промежуточным фолдам).
2. Сравни с random search при том же бюджете.
3. **Симуляция смещения отбора:** 200 «моделей» с одинаковым истинным качеством 0,8 и шумом оценки σ = 0,02. Найди распределение максимума оценок, сравни с формулой $0{,}8 + \sigma\sqrt{2\ln m}$ для $m = 10, 100, 1000$. Объясни, что это значит для лидербордов Kaggle и для выбора эпохи по валидации.
