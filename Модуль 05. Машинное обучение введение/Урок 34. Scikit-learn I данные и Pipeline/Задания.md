**🟢 Базовое — «Titanic без утечек»** (`titanic.py`)
Данные: `fetch_openml("titanic", version=1, as_frame=True)` (или CSV с Kaggle).
1. Разбей на train/test со стратификацией по `survived`.
2. `ColumnTransformer`: числовые (`age`, `fare`) — медиана + индикатор + масштаб; категориальные (`sex`, `embarked`, `pclass`) — one-hot; `fare` — `log1p` перед масштабом.
3. Пайплайн с логистической регрессией; `cross_val_score` на **сыром** DataFrame train. Итог — на test один раз.
4. Найди в датасете колонки-утечки (подсказка: `boat`, `body`) и объясни, почему их нельзя использовать.

**🟡 Среднее — «Правильный сплит для кадров»** (`frame_split.py`)
Сгенерируй «датасет кадров»: 80 видео с 4 камер, 30–200 кадров на видео, признаки кадра = признаки видео + малый шум, редкий класс «инцидент» (3% кадров, сгруппирован по видео).
1. Сравни оценки ROC-AUC для `KFold`, `StratifiedKFold`, `GroupKFold`, `StratifiedGroupKFold` по видео и «leave-one-camera-out» (`LeaveOneGroupOut` по камерам).
2. Объясни, какая оценка отвечает на вопрос «как модель сработает на новых видео с тех же камер», а какая — «на новой камере».
3. Проверь, в каких фолдах `GroupKFold` не оказалось ни одного инцидента, и как это исправляет `StratifiedGroupKFold`.

**🔴 Со звёздочкой — «Свой ColumnTransformer»** (`mini_column_transformer.py` + `test_mini_column_transformer.py`)
1. Реализуй `MiniColumnTransformer(transformers=[(name, transformer, columns)], remainder="drop"|"passthrough")` для pandas DataFrame: `fit`, `transform`, `fit_transform`, `get_feature_names_out` с префиксами `name__`.
2. Наследуйся от `BaseEstimator, TransformerMixin`; поддержи вложенные параметры для `GridSearchCV` (`"num__scale__with_mean"`) — разберись, как это делает `get_params(deep=True)`.
3. Тесты: результат совпадает со `sklearn.compose.ColumnTransformer` на данных урока; работает внутри `Pipeline` и `cross_val_score`; `clone` создаёт независимую копию.
