## 1. Зачем это нужно

- **Градиент** — направление обновления весов в каждом оптимизаторе, от SGD до Adam.
- **Якобиан** — «производная слоя». Backprop в тензорном виде — это умножение градиента на транспонированные якобианы слоёв, причём сами якобианы никогда не строятся явно. Отсюда формулы `dW = dY.T @ X`, которые ты будешь писать в уроке 63.
- **Гессиан** — кривизна функции потерь. Он объясняет выбор learning rate (урок 6), почему Adam и BatchNorm помогают и почему в глубоких сетях больше проблем с седловыми точками, чем с локальными минимумами.
- **Множители Лагранжа** — оптимизация с ограничениями: PCA (максимум дисперсии при единичной норме) и двойственная задача SVM (урок 41).

## 2. Интуиция

- **Градиент** $\nabla f$ — стрелка в пространстве параметров, указывающая, куда функция растёт быстрее всего. Её длина — насколько быстро. Градиент перпендикулярен линиям уровня, как стрелка «вверх по склону» на топографической карте перпендикулярна горизонталям.
- **Якобиан** — то же самое для функции с многими выходами. Это матрица, которая говорит, как каждый выход реагирует на каждый вход. Вблизи точки любая гладкая функция $\mathbb{R}^n \to \mathbb{R}^m$ выглядит как матрица (линейное отображение, урок 4) — это и есть якобиан.
- **Гессиан** — «производная градиента», матрица кривизны. Его собственные векторы (урок 6) — главные оси «чаши», а собственные значения — насколько круто чаша изгибается вдоль каждой оси. Все $\lambda > 0$ — чаша (минимум); все $< 0$ — купол (максимум); разные знаки — седло (горный перевал).

## 3. Математика

### 3.1. Градиент и производная по направлению

Для $f: \mathbb{R}^n \to \mathbb{R}$: $\nabla f(x) = \Big(\dfrac{\partial f}{\partial x_1}, \dots, \dfrac{\partial f}{\partial x_n}\Big)^\top$, и

$$f(x + h) = f(x) + \nabla f(x)^\top h + o(\|h\|).$$

**Производная по направлению** единичного $u$: $D_u f = \nabla f^\top u$.

**Почему антиградиент — направление наискорейшего спуска.** По неравенству Коши–Буняковского (урок 3) $\nabla f^\top u \ge -\|\nabla f\|\,\|u\| = -\|\nabla f\|$, причём равенство достигается при $u = -\nabla f/\|\nabla f\|$. Значит, среди всех направлений единичной длины быстрее всего $f$ убывает вдоль $-\nabla f$.

**Градиент перпендикулярен линиям уровня:** вдоль линии уровня $f$ не меняется, то есть $\nabla f^\top u = 0$ для касательного $u$.

### 3.2. Якобиан и цепное правило в матричной форме

Для $f: \mathbb{R}^n \to \mathbb{R}^m$ якобиан $J_f \in \mathbb{R}^{m \times n}$, $(J_f)_{ij} = \partial f_i/\partial x_j$, и $f(x + h) \approx f(x) + J_f h$.

**Цепное правило:** для $z = f(g(x))$

$$J_{f\circ g}(x) = J_f\big(g(x)\big)\cdot J_g(x).$$

Композиция функций — произведение их линейных приближений, то есть матриц (урок 4: умножение матриц = композиция). Скалярное цепное правило из урока 9 — частный случай с матрицами $1 \times 1$, а «сумма по путям» — это и есть формула произведения матриц $\sum_k (J_f)_{ik}(J_g)_{kj}$.

**Якобианы типовых слоёв:**

| Слой | Якобиан |
|---|---|
| Линейный $y = Wx$ | $W$ |
| Поэлементная функция $y_i = \phi(x_i)$ (ReLU, tanh) | $\operatorname{diag}(\phi'(x))$ |
| Softmax $p_i = e^{z_i}/\sum_k e^{z_k}$ | $\operatorname{diag}(p) - pp^\top$ |

**Вывод якобиана softmax.** $\dfrac{\partial p_i}{\partial z_j} = \dfrac{\delta_{ij}e^{z_i}S - e^{z_i}e^{z_j}}{S^2} = p_i\delta_{ij} - p_ip_j$, где $S = \sum_k e^{z_k}$.

**Softmax + кросс-энтропия.** $L = -\log p_c$ для истинного класса $c$. Тогда $\dfrac{\partial L}{\partial p_i} = -\dfrac{\delta_{ic}}{p_c}$, и по цепному правилу

$$\frac{\partial L}{\partial z_j} = \sum_i \frac{\partial L}{\partial p_i}\frac{\partial p_i}{\partial z_j} = -\frac{1}{p_c}\,p_c(\delta_{cj} - p_j) = p_j - \delta_{cj} \quad\Longrightarrow\quad \nabla_z L = p - y_{\text{onehot}}.$$

Самая важная формула классификации: градиент по логитам — «предсказанное минус истинное». Поэтому в PyTorch есть `nn.CrossEntropyLoss`, принимающая логиты: связка softmax+CE устойчивее и проще, чем по отдельности.

### 3.3. Backprop = произведения вектора на якобиан (VJP)

Для потери $L$ и слоя $y = f(x)$ из цепного правила: $\bar x^\top = \bar y^\top J_f$, то есть

$$\bar x = J_f^\top\,\bar y.$$

Якобиан линейного слоя на батче огромен (выход × вход × размер батча), но **строить его не нужно**: нужна только операция «умножить $\bar y$ на $J^\top$». Её называют VJP (vector–Jacobian product), и у каждой операции PyTorch есть своя формула VJP.

**Линейный слой на батче** $Y = XW^\top + b$, $X \in \mathbb{R}^{N\times d_{in}}$, $W \in \mathbb{R}^{d_{out}\times d_{in}}$. Пусть пришёл $\bar Y = \partial L/\partial Y$ той же формы, что $Y$. По определению $Y_{nk} = \sum_j X_{nj}W_{kj} + b_k$, значит

$$\bar W_{kj} = \sum_n \bar Y_{nk}X_{nj} \Rightarrow \bar W = \bar Y^\top X, \qquad \bar X = \bar Y W, \qquad \bar b = \sum_n \bar Y_{n\cdot}.$$

**Правило совпадения форм** (практический трюк): $\bar W$ должен иметь форму $W$ $(d_{out}\times d_{in})$. Из множителей $\bar Y$ $(N \times d_{out})$ и $X$ $(N \times d_{in})$ такая форма получается единственным способом: $\bar Y^\top X$. Это не доказательство, но отличная проверка.

### 3.4. Таблица матричных производных

| $f(x)$ | $\nabla_x f$ | Вывод |
|---|---|---|
| $a^\top x$ | $a$ | $\partial_i \sum_j a_jx_j = a_i$ |
| $x^\top A x$ | $(A + A^\top)x$, для симметричной $2Ax$ | $\partial_i \sum_{jk}x_jA_{jk}x_k = \sum_k A_{ik}x_k + \sum_j x_jA_{ji}$ |
| $\|Ax - b\|^2$ | $2A^\top(Ax - b)$ | цепное правило: $\nabla_r\|r\|^2 = 2r$, $J_r = A$ |
| $\|x\|_2$ | $x/\|x\|$ | $\frac{1}{2\|x\|}\cdot 2x$ |
| $\log\sum_i e^{x_i}$ | $\operatorname{softmax}(x)$ | |

Гессианы: $\nabla^2(x^\top Ax) = A + A^\top$; $\nabla^2\|Ax - b\|^2 = 2A^\top A$.

### 3.5. Гессиан и классификация критических точек

$H_{ij} = \dfrac{\partial^2 f}{\partial x_i\partial x_j}$. Для гладких функций $H$ симметричен (теорема Шварца). Ряд Тейлора второго порядка:

$$f(x + h) = f(x) + \nabla f^\top h + \tfrac12 h^\top H h + o(\|h\|^2).$$

В критической точке ($\nabla f = 0$) всё решает квадратичная форма $h^\top Hh = \sum_i\lambda_ic_i^2$ (урок 6, 3.4):
- все $\lambda_i > 0$ — **минимум**;
- все $\lambda_i < 0$ — **максимум**;
- есть разные знаки — **седло**;
- есть нулевые — нужен анализ высших порядков (плоские направления типичны для перепараметризованных сетей).

**Седла в высоких размерностях.** Если бы знак каждого $\lambda_i$ был «монеткой», вероятность, что все $10^6$ знаков положительны, была бы $2^{-10^6}$. Это грубая эвристика, но она объясняет, почему в больших сетях критические точки с высокой потерей почти всегда — **седла**, а не плохие локальные минимумы. Точный GD может застрять в седле. Шум SGD выталкивает из него вдоль направления с $\lambda < 0$: сначала медленно, потом экспоненциально быстро (это видно в коде).

**Гессианы типовых потерь:**
- MSE линейной регрессии: $H = \frac{2}{n}X^\top X \succeq 0$ — выпукла.
- Логистическая потеря: $H = \frac1n X^\top\operatorname{diag}\big(p(1-p)\big)X \succeq 0$ — выпукла. Значит, у логистической регрессии нет плохих локальных минимумов.
- Нейросеть: гессиан не PSD, функция невыпукла.

### 3.6. Метод Ньютона

Минимизируем квадратичную модель Тейлора по $h$: $\nabla_h\big(\nabla f^\top h + \frac12h^\top Hh\big) = \nabla f + Hh = 0$, откуда

$$x_{k+1} = x_k - H^{-1}\nabla f(x_k).$$

- На квадратичной функции — **один шаг** до минимума, при любой обусловленности. Ньютон «переобусловливает» задачу: в собственном базисе $H$ каждое направление делится на свою кривизну.
- Возле минимума — квадратичная сходимость (число верных знаков удваивается на каждом шаге).
- **Почему не в DL:** гессиан $n \times n$ для $n = 10^7$ весов — это $10^{14}$ чисел, а решение системы стоит $O(n^3)$. Кроме того, в седлах $H$ не PSD, и Ньютон идёт **к** седлу. Практические компромиссы — квазиньютоновские методы (L-BFGS, используется в `LogisticRegression` sklearn) и диагональные приближения кривизны (идея Adam, урок 66).

### 3.7. Множители Лагранжа

Задача: $\max f(x)$ при $g(x) = 0$. В оптимуме нельзя сдвинуться вдоль поверхности $g = 0$ и увеличить $f$. Значит, $\nabla f$ перпендикулярен поверхности, то есть параллелен $\nabla g$:

$$\nabla f(x) = \lambda\,\nabla g(x).$$

Эквивалентно: стационарная точка лагранжиана $\mathcal{L}(x, \lambda) = f(x) - \lambda g(x)$.

**Пример: PCA из ограничения.** Максимизируем дисперсию проекции $v^\top Cv$ при $v^\top v = 1$:

$$\nabla_v(v^\top Cv) = 2Cv = \lambda\cdot 2v \quad\Longrightarrow\quad Cv = \lambda v.$$

Стационарные точки — собственные векторы $C$, а значение $v^\top Cv = \lambda v^\top v = \lambda$. Максимум — главный собственный вектор. Это тот же результат, что отношение Рэлея из урока 6, полученный третьим способом. Для ограничений-неравенств (SVM, урок 41) обобщение называется условиями Каруша–Куна–Таккера (KKT).

## 4. Реализация с нуля на NumPy

Файл: [код/matrix_calculus.py](код/matrix_calculus.py):

```python
def numeric_jacobian(f, x, h=1e-6):
    fx = np.atleast_1d(f(x))
    J = np.zeros((fx.size, x.size))
    for j in range(x.size):
        e = np.zeros_like(x)
        e.flat[j] = h
        J[:, j] = (np.atleast_1d(f(x + e)) - np.atleast_1d(f(x - e))).ravel() / (2 * h)
    return J

def softmax_jacobian(z):
    p = softmax(z)
    return np.diag(p) - np.outer(p, p)

def linear_backward(X, W, dY):
    return dY.T @ X, dY @ W, dY.sum(axis=0)

def logistic_hessian(w, X, y):
    p = 1 / (1 + np.exp(-X @ w))
    return (X.T * (p * (1 - p))) @ X / len(y)    # X^T diag(p(1-p)) X — PSD, значит потеря выпукла
```

`(X.T * d) @ X` вместо `X.T @ np.diag(d) @ X` — тот же трюк, что `U * s` в уроке 7: умножение на диагональную матрицу через broadcasting, без матрицы $n \times n$.

```

суммы строк якобиана softmax ≈ 0: True
grad CE(softmax) = p - y: True
dW линейного слоя совпадает с численным: True
градиент логистической потери верен: True
гессиан логистической потери верен: True
собственные значения гессиана (все ≥ 0 -> выпукла): [0.2302 0.2507 0.2899]

```

Строки якобиана softmax суммируются в ноль: если добавить ко всем логитам одно и то же число, вероятности не изменятся. Значит, вектор $(1, \dots, 1)$ лежит в ядре якобиана.

Для проверки $\bar W$ использован приём: если $L = \langle Y, \bar Y\rangle = \sum Y \odot \bar Y$ с фиксированной $\bar Y$, то $\partial L/\partial Y = \bar Y$. Так любой VJP можно проверить численно через скалярную функцию.

- **Функция Розенброка** — классический тест оптимизаторов: узкая изогнутая долина. Гессиан в минимуме имеет $\kappa \approx 2500$. GD нужно 43 605 шагов, Ньютону — 6. Это раздел 3.6 и урок 6 в одном примере.
- **Седло** $x^2 - y^2$: из точной точки $(1, 0)$ GD сходится прямо в седло $(0, 0)$ и застревает. Стоит сдвинуть старт на $10^{-8}$, и координата $y$ растёт как $1{,}2^k$: за 60 шагов в 56 000 раз, а дальше экспоненциально. Шум SGD играет роль этого сдвига.
- **Лагранж** через численную оптимизацию с ограничением (`scipy.optimize.minimize`, SLSQP) нашёл тот же вектор, что `eigh` (с точностью до знака), и то же значение $\lambda_{\max}$.

## 6. Типичные ошибки и как их отлаживать

| Ошибка | Симптом | Как правильно |
|---|---|---|
| `dW = X.T @ dY` для весов формы `(out, in)` | Форма `(in, out)`, для квадратного слоя ошибки нет, а градиент транспонирован | Правило совпадения форм + gradient check |
| Отдельно softmax, затем `log`, затем NLL | `log(0) = -inf`, NaN при уверенных предсказаниях | `nn.CrossEntropyLoss` на логитах (log-sum-exp внутри) |
| Забыли нормировку $1/N$ в градиенте средней потери | Эффективный learning rate зависит от размера батча | Согласовать определение потери (`mean` или `sum`) и градиента |
| Явное построение якобиана для backprop | Память $O(\text{выход} \times \text{вход})$ | Только VJP; в PyTorch `torch.autograd.grad` с `grad_outputs` |
| Ньютон без проверки PSD гессиана | Шаг ведёт к седлу или максимуму | Демпфирование $H + \mu I$ (Левенберг–Марквардт) или квазиньютоновские методы |
| Остановка по «градиент маленький» | Может быть седло или плато | Смотреть на спектр гессиана (хотя бы $\lambda_{\min}$ степенным методом) или на потерю на валидации |

## Ответы на вопросы для самопроверки

1. $D_uf = \nabla f^\top u \ge -\|\nabla f\|$ по Коши–Буняковскому, равенство при $u = -\nabla f/\|\nabla f\|$. Вдоль линии уровня $f$ постоянна, значит $D_uf = \nabla f^\top u = 0$ для касательных $u$ — градиент им ортогонален.
2. Градиент — для скалярной функции (вектор, или якобиан $1 \times n$, транспонированный). Якобиан — для векторной ($m \times n$). $J_{f\circ g} = J_f J_g$: линейное приближение композиции — композиция линейных приближений, а композиция линейных отображений — произведение матриц.
3. См. 3.2: $\partial p_i/\partial z_j = p_i(\delta_{ij} - p_j)$, $\partial L/\partial p_i = -\delta_{ic}/p_c$; сумма даёт $p_j - \delta_{cj}$, то есть $\nabla_zL = p - y$.
4. $\bar W = \bar Y^\top X$, $\bar X = \bar YW$, $\bar b = \sum_n\bar Y_n$ (вывод покомпонентный, 3.3). VJP — произведение $J^\top\bar y$, вычисляемое без построения $J$. Якобиан огромен ($O(\text{выход}\cdot\text{вход})$), а VJP стоит как прямой проход.
5. По знакам собственных значений гессиана: все положительные — минимум, все отрицательные — максимум, разные — седло. В высокой размерности требование «все $\lambda > 0$» очень сильное, поэтому большинство критических точек — седла.
6. Минимизация квадратичной модели $f + g^\top h + \frac12h^\top Hh$ даёт $h = -H^{-1}g$. Для нейросетей гессиан слишком велик ($n^2$ памяти, $O(n^3)$ на решение), а в невыпуклом случае Ньютон притягивается к седлам.
7. $\mathcal{L} = v^\top Cv - \lambda(v^\top v - 1)$, $\nabla_v\mathcal{L} = 2Cv - 2\lambda v = 0 \Rightarrow Cv = \lambda v$. Значение цели $v^\top Cv = \lambda$, максимум — у главного собственного вектора.
