## 1. Зачем это нужно

- **Выход нейросети — распределение.** Softmax выдаёт PMF над классами. Регрессия рамки с неопределённостью выдаёт параметры плотности (среднее и дисперсию). Функция потерь — это «насколько вероятны истинные ответы под предсказанным распределением» (урок 15).
- **Функция потерь — матожидание.** Мы минимизируем $\mathbb{E}_{(x,y)}[\ell(f(x), y)]$, а мини-батч — это Монте-Карло-оценка этого матожидания. Шум SGD — дисперсия этой оценки, и она падает как $1/\text{batch}$.
- **Нормализация.** `Normalize(mean, std)` в torchvision, BatchNorm, `StandardScaler` — это вычитание матожидания и деление на стандартное отклонение.
- **Ковариация** — основа PCA (урок 48), многомерной нормали (урок 15), whitening и мультиколлинеарности (урок 5).

## 2. Интуиция

**Случайная величина** — не «случайное число», а **функция** от исхода эксперимента: каждому исходу (кадру) сопоставляется число (сколько на нём объектов, средняя яркость, IoU предсказания).

- **Дискретная** величина описывается **PMF** — таблицей «значение → вероятность».
- **Непрерывная** — **плотностью (PDF)**. Плотность — это не вероятность, а «вероятность на единицу длины». Вероятность попасть в интервал — **площадь** под плотностью, а вероятность попасть ровно в точку равна нулю. Плотность может быть больше 1.
- **CDF** $F(x) = P(X \le x)$ работает для обоих типов. Обратная к ней (квантильная функция) отвечает на вопрос «какое значение не превышается в 95% случаев».

**Матожидание** — центр масс распределения. **Дисперсия** — разброс вокруг него (момент инерции). **Ковариация** — насколько две величины «ходят вместе».

## 3. Математика

### 3.1. Определения

| | Дискретная | Непрерывная |
|---|---|---|
| Распределение | PMF $p(x) = P(X = x)$, $\sum_x p(x) = 1$ | PDF $f(x) \ge 0$, $\int f = 1$, $P(a \le X \le b) = \int_a^b f$ |
| CDF | $F(x) = \sum_{t \le x}p(t)$ | $F(x) = \int_{-\infty}^x f$, $f = F'$ |
| $\mathbb{E}[X]$ | $\sum_x x\,p(x)$ | $\int x f(x)\,dx$ |
| $\mathbb{E}[g(X)]$ (LOTUS) | $\sum_x g(x)p(x)$ | $\int g(x)f(x)\,dx$ |

**LOTUS** («закон бессознательного статистика»): чтобы найти $\mathbb{E}[g(X)]$, не нужно сначала искать распределение $g(X)$.

### 3.2. Линейность матожидания

$$\mathbb{E}[aX + bY + c] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y] + c \quad\text{— даже для зависимых } X, Y.$$

Доказательство (дискретный случай): $\mathbb{E}[X + Y] = \sum_{x,y}(x + y)p(x,y) = \sum_x x\sum_y p(x,y) + \sum_y y\sum_x p(x,y) = \sum_x x\,p(x) + \sum_y y\,p(y)$. Независимость нигде не использовалась.

**Индикаторы.** $I_A = 1$, если $A$ случилось, иначе 0; $\mathbb{E}[I_A] = P(A)$. Число событий — сумма индикаторов, и по линейности его среднее — сумма вероятностей. Отсюда «ожидаемое число ложных срабатываний = $np$» из урока 12, причём **без** предположения независимости.

**Но** $\mathbb{E}[g(X)] \neq g(\mathbb{E}[X])$ для нелинейных $g$. **Неравенство Йенсена:** для выпуклой $g$ $\mathbb{E}[g(X)] \ge g(\mathbb{E}[X])$, для вогнутой (например, $\log$) — наоборот. Это основа вывода ELBO в вариационных автоэнкодерах (урок 86) и объяснение, почему «средняя потеря» ≠ «потеря на среднем».

### 3.3. Дисперсия

$$\operatorname{Var}(X) = \mathbb{E}\big[(X - \mu)^2\big] = \mathbb{E}[X^2] - \mu^2.$$

Вывод второй формы: $\mathbb{E}[X^2 - 2\mu X + \mu^2] = \mathbb{E}[X^2] - 2\mu^2 + \mu^2$.

Свойства:
- $\operatorname{Var}(aX + b) = a^2\operatorname{Var}(X)$ — сдвиг не меняет разброс, масштаб — квадратично;
- $\operatorname{Var}(X + Y) = \operatorname{Var}X + \operatorname{Var}Y + 2\operatorname{Cov}(X, Y)$;
- для независимых ковариация 0 и дисперсии складываются.

**Дисперсия среднего.** Для независимых $X_1..X_n$ с дисперсией $\sigma^2$:

$$\operatorname{Var}(\bar X) = \frac{1}{n^2}\sum_i\operatorname{Var}(X_i) = \frac{\sigma^2}{n}, \qquad \operatorname{std}(\bar X) = \frac{\sigma}{\sqrt n}.$$

Это строгое обоснование «$1/\sqrt n$» из урока 12. В SGD то же самое: градиент по батчу размера $B$ — среднее $B$ градиентов, его шум $\propto 1/\sqrt B$. Поэтому при увеличении батча learning rate часто увеличивают.

**Почему выборочную дисперсию делят на $n - 1$.** $\mathbb{E}\big[\sum(X_i - \bar X)^2\big] = (n-1)\sigma^2$: одна «степень свободы» тратится на оценку среднего. В NumPy `np.var` по умолчанию делит на $n$ (`ddof=0`), `np.cov` — на $n-1$, а pandas `.var()` — на $n-1$. Разница видна только на маленьких выборках.

### 3.4. Ковариация и корреляция

$$\operatorname{Cov}(X, Y) = \mathbb{E}\big[(X - \mu_X)(Y - \mu_Y)\big], \qquad \rho = \frac{\operatorname{Cov}(X,Y)}{\sigma_X\sigma_Y} \in [-1, 1].$$

Граница $|\rho| \le 1$ — снова Коши–Буняковский (урок 3): ковариация — это скалярное произведение центрированных величин.

**Независимость ⇒ некоррелированность, но не наоборот.** Корреляция ловит только **линейную** связь. $X \sim \mathcal{N}(0,1)$ и $Y = X^2$: $\operatorname{Cov} = \mathbb{E}[X^3] - \mathbb{E}[X]\mathbb{E}[X^2] = 0$, хотя $Y$ полностью определяется $X$.

**Ковариационная матрица** вектора $X \in \mathbb{R}^d$: $\Sigma = \mathbb{E}\big[(X - \mu)(X - \mu)^\top\big]$. Она симметрична и PSD (урок 6). Для линейного преобразования:

$$\operatorname{Cov}(AX + b) = A\,\Sigma\,A^\top.$$

Вывод: $\mathbb{E}\big[A(X - \mu)(X - \mu)^\top A^\top\big] = A\,\mathbb{E}[\dots]\,A^\top$ (линейность). Следствия:
- дисперсия проекции на единичный $v$ — $v^\top\Sigma v$ (это и было в уроке 6, 3.5);
- **whitening**: $A = \Sigma^{-1/2}$ даёт $\operatorname{Cov} = I$ — некоррелированные признаки единичной дисперсии.

### 3.5. Метод обратного преобразования

Если $U \sim \text{Uniform}(0, 1)$ и $F$ — непрерывная строго возрастающая CDF, то $X = F^{-1}(U)$ имеет CDF $F$. Доказательство: $P(X \le x) = P(F^{-1}(U) \le x) = P(U \le F(x)) = F(x)$. Так из равномерного генератора делают любые распределения. Для экспоненциального $F^{-1}(u) = -\ln(1 - u)/\lambda$.

## 6. Типичные ошибки и как их отлаживать

| Ошибка | Последствие | Как правильно |
|---|---|---|
| Плотность как вероятность | «$f(x) = 4$, значит вероятность 400%?» | Вероятность — площадь: `cdf(b) - cdf(a)` |
| $\mathbb{E}[g(X)] = g(\mathbb{E}[X])$ | Неверные оценки: например, IoU средней рамки ≠ средний IoU | LOTUS / Монте-Карло по сэмплам |
| `ddof` | `np.var` (÷n) против pandas `.var()` (÷n−1) дают разные числа | Явно указывать `ddof` |
| `np.cov(X)` для матрицы `(n, d)` | Получается `(n, n)` | `rowvar=False` |
| «Корреляция 0 → независимы» | Пропущена нелинейная связь | Смотреть scatter plot (урок 17), взаимную информацию |
| Нормализация по статистикам не того набора | Утечка (урок 1) или несоответствие предобученной модели | ImageNet-статистики для предобученных бэкбонов; свои — только по train |

## Ответы на вопросы для самопроверки

1. PMF — вероятности отдельных значений (дискретный случай), PDF — плотность (непрерывный случай), вероятность точки = 0. Плотность может быть больше 1 (Uniform(0; 0,25) имеет плотность 4). Вероятность интервала — интеграл плотности: $F(b) - F(a)$.
2. $\mathbb{E}[X+Y] = \sum_{x,y}(x+y)p(x,y)$; сумма разбивается на две, и маргинализация даёт $\mathbb{E}X + \mathbb{E}Y$. Независимость не нужна.
3. Раскрываем квадрат и пользуемся линейностью. Для среднего независимых: $\operatorname{Var}(\frac1n\sum X_i) = \frac{1}{n^2}\cdot n\sigma^2$. Градиент по батчу — среднее $B$ градиентов, его шум $\propto 1/\sqrt B$: больший батч даёт менее шумный градиент и позволяет больший шаг.
4. $\operatorname{Cov}(AX) = \mathbb{E}[A(X-\mu)(X-\mu)^\top A^\top] = A\Sigma A^\top$. Для $A = v^\top$: $\operatorname{Var}(v^\top X) = v^\top\Sigma v$.
5. $X \sim \mathcal{N}(0,1)$, $Y = X^2$: ковариация $\mathbb{E}[X^3] = 0$, а зависимость полная.
6. Метод обратного преобразования: $X = F^{-1}(U)$, $U \sim \text{Uniform}(0,1)$, так как $P(F^{-1}(U) \le x) = P(U \le F(x)) = F(x)$.
7. $\log$ вогнут, поэтому $\mathbb{E}[\log X] \le \log\mathbb{E}[X]$. На этом построена нижняя оценка правдоподобия (ELBO) в VAE.
