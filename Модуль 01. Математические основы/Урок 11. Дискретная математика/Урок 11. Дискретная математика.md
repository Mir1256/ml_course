## 1. Зачем это нужно

Дискретная математика в ML — «тихая» тема: о ней редко говорят, но она везде.
- **IoU** — мера Жаккара двух множеств пикселей. На ней построены метрики детекции и сегментации (урок 60), NMS и сопоставление предсказаний с разметкой.
- **Графы** — компоненты связности масок (сколько отдельных объектов в маске сегментации), вычислительный граф autograd (урок 9 — это ориентированный ациклический граф, DAG, и его топологическая сортировка), графовые нейросети, иерархическая кластеризация (урок 46).
- **Комбинаторика** объясняет, почему нельзя перебрать все подмножества признаков (урок 31) или всю сетку гиперпараметров (урок 35), и считает вероятности (урок 12).
- **O-нотация** решает, будет ли твой скрипт аудита разметки работать 2 секунды или 2 дня.

## 2. Интуиция

- **Множество** — набор различных элементов без порядка. Маска объекта — множество пикселей, рамка — множество точек плоскости. Пересечение, объединение и разность — то, что делают `&`, `|`, `& ~` с булевыми масками.
- **Логика** — язык условий. «Для всех» ($\forall$) и «существует» ($\exists$) при отрицании меняются местами. Дерево решений (урок 42) — это логическая формула из условий вида «признак > порог».
- **Комбинаторика** — умение считать варианты, не перечисляя их.
- **Граф** — вершины и рёбра. Пиксели маски с рёбрами между соседями; объекты на кадрах видео с рёбрами «это один и тот же объект» (трекинг); слои сети с рёбрами «выход идёт на вход».
- **O-нотация** описывает, как растёт время с ростом входа, без учёта констант. $O(n^2)$ на 10 000 рамок — это $10^8$ операций, на 100 000 — уже $10^{10}$.

## 2б. Освежение базы

**Множества.** $|A \cup B| = |A| + |B| - |A \cap B|$ (включения-исключения). Законы де Моргана: $\overline{A \cup B} = \bar A \cap \bar B$, $\overline{A \cap B} = \bar A \cup \bar B$.

**Логика.** $\neg(\forall x\, P(x)) \equiv \exists x\,\neg P(x)$; $\neg(\exists x\, P(x)) \equiv \forall x\,\neg P(x)$. Импликация $P \Rightarrow Q$ ложна только при истинном $P$ и ложном $Q$.

**Комбинаторика.**
- Правило произведения: независимые выборы перемножаются (размер сетки гиперпараметров — произведение размеров осей).
- Перестановки: $n!$. Размещения $k$ из $n$ (упорядоченно): $\frac{n!}{(n-k)!}$.
- Сочетания $k$ из $n$ (без порядка): $\binom{n}{k} = \frac{n!}{k!(n-k)!}$.
- Число подмножеств: $2^n$ (каждый элемент «берём или нет»).
- Принцип Дирихле: если $n + 1$ объект разложить по $n$ ящикам, в каком-то ящике окажется хотя бы два.

**Графы.** Степень вершины; путь; цикл; связность; компонента связности; дерево — связный граф без циклов, у него ровно $n - 1$ ребро. DAG — ориентированный граф без циклов; у него есть топологический порядок (каждая вершина раньше всех, в которые из неё идут рёбра).

**Обходы.** BFS (в ширину, через очередь) и DFS (в глубину, через стек или рекурсию). Оба — $O(V + E)$.

**O-нотация.** $f(n) = O(g(n))$, если $f(n) \le c\,g(n)$ для всех достаточно больших $n$. Иерархия: $O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)$.

## 3. Математика

### 3.1. IoU через включения-исключения

$$\text{IoU}(A, B) = \frac{|A \cap B|}{|A \cup B|} = \frac{|A \cap B|}{|A| + |B| - |A \cap B|} \in [0, 1].$$

Пересечение двух выровненных по осям прямоугольников — снова прямоугольник (или пустое множество):

$$w_\cap = \max\big(0,\ \min(x_2, x_2') - \max(x_1, x_1')\big), \quad h_\cap = \max\big(0,\ \min(y_2, y_2') - \max(y_1, y_1')\big).$$

Мера $1 - \text{IoU}$ — **метрика** на множествах (расстояние Жаккара): удовлетворяет неравенству треугольника. Отсюда устойчивость кластеризации рамок по IoU (так YOLOv2 подбирал якоря через k-means).

Важное свойство: IoU не дифференцируема там, где рамки не пересекаются (там она тождественно 0). Поэтому для обучения регрессии рамок придумали GIoU, DIoU и CIoU. В них добавлен штраф за расстояние между рамками, и градиент есть даже без пересечения.

### 3.2. Компоненты связности и сложность

Граф маски: вершины — пиксели со значением `True`, рёбра — между соседями. **4-связность** — соседи по сторонам, **8-связность** — ещё и по диагоналям. Выбор меняет ответ: диагональная линия — 4 объекта при 4-связности и 1 объект при 8-связности.

BFS посещает каждый пиксель и проверяет 4 или 8 соседей: $O(HW)$ — линейно по числу пикселей. Альтернатива — система непересекающихся множеств (union-find) с двухпроходной разметкой. Её используют `scipy.ndimage.label` и OpenCV `connectedComponents`.

### 3.3. Сложность NMS

Жадный NMS: сортировка по уверенности $O(n\log n)$, затем каждая оставленная рамка сравнивается со всеми оставшимися. В худшем случае (рамки не подавляют друг друга) это $\frac{n(n-1)}{2} = O(n^2)$ вычислений IoU. Для 8400 предсказаний YOLO на кадр это ≈ 35 млн пар. Поэтому:
- перед NMS отсекают рамки по порогу уверенности: $n$ падает до сотен;
- NMS делают по классам (batched NMS) — сравнение только внутри класса;
- YOLO26 убрал NMS вовсе: сеть сразу выдаёт по одному предсказанию на объект (end-to-end).

### 3.4. Комбинаторный взрыв

- **Отбор признаков:** проверить все подмножества 30 признаков — $2^{30} \approx 10^9$ обучений модели. Отсюда жадные методы и регуляризация (урок 31, Lasso в уроке 39).
- **Сетка гиперпараметров:** правило произведения. 5 параметров по 3–6 значений — уже 1080 запусков. Отсюда случайный поиск и байесовская оптимизация (урок 35).
- **Парадокс дней рождения** (связь с уроком 12): среди $n$ случайных значений из $N$ возможных вероятность совпадения становится заметной уже при $n \approx \sqrt{N}$. Это причина коллизий хэшей при поиске дубликатов кадров.

## 4. Реализация с нуля

Файл: [код/discrete.py](код/discrete.py).

```python
def box_iou(b1, b2):
    iw = max(0.0, min(b1[2], b2[2]) - max(b1[0], b2[0]))
    ih = max(0.0, min(b1[3], b2[3]) - max(b1[1], b2[1]))
    inter = iw * ih
    area = lambda b: (b[2] - b[0]) * (b[3] - b[1])
    return inter / (area(b1) + area(b2) - inter)            # формула включений-исключений: |A∪B| = |A|+|B|-|A∩B|


def connected_components(mask, connectivity=4):
    labels = np.zeros(mask.shape, dtype=int)
    steps = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    if connectivity == 8:
        steps += [(-1, -1), (-1, 1), (1, -1), (1, 1)]
    current = 0
    H, W = mask.shape
    for i, j in product(range(H), range(W)):
        if mask[i, j] and labels[i, j] == 0:
            current += 1
            labels[i, j] = current
            queue = deque([(i, j)])
            while queue:
                y, x = queue.popleft()
                for dy, dx in steps:
                    ny, nx = y + dy, x + dx
                    if 0 <= ny < H and 0 <= nx < W and mask[ny, nx] and labels[ny, nx] == 0:
                        labels[ny, nx] = current
                        queue.append((ny, nx))
    return labels, current


def nms(boxes, scores, iou_thr=0.5):
    order = list(np.argsort(scores)[::-1])                   # сортировка O(n log n)
    keep = []
    while order:
        best = order.pop(0)
        keep.append(int(best))
        order = [i for i in order if box_iou(boxes[best], boxes[i]) < iou_thr]
    return keep
```

## 6. Типичные ошибки и как их отлаживать

| Ошибка | Последствие | Как правильно |
|---|---|---|
| Пиксельные vs непрерывные координаты рамок | IoU отличается на «+1»: в старом коде VOC площадь считали как `(x2 - x1 + 1)` | Зафиксировать соглашение датасета и проверить на простом примере |
| Деление на ноль в IoU | Две рамки нулевой площади → `nan` | `eps` в знаменателе или явная проверка |
| Не та связность | Тонкие диагональные объекты распадаются на куски (или соседние сливаются) | Осознанный выбор 4/8; проверка на диагональной линии |
| Рекурсивный DFS на большой маске | `RecursionError` (лимит Python ≈ 1000) | BFS с очередью или итеративный DFS со стеком |
| NMS по всем классам сразу | Подавляются пересекающиеся объекты **разных** классов (человек на велосипеде) | Batched NMS по классам |
| Попарные сравнения в Python-цикле | Часы вместо секунд | Сортировка, хэш-таблицы (`dict`/`set` — $O(1)$ поиск), векторизация |

## Ответы на диагностику

1. $A \cap B = \{3, 4\}$, $A \cup B = \{1, 2, 3, 4, 5\}$, $A \setminus B = \{1, 2\}$, $|A \cup B| = 4 + 3 - 2 = 5$.
2. $\binom{10}{3} = 120$; $10 \cdot 9 \cdot 8 = 720$; $2^{10} = 1024$.
3. «Существует кадр, на котором у всех объектов уверенность ≤ 0,5» (включая кадры без объектов).
4. Две компоненты: $\{1, 2, 3\}$ и $\{4, 5\}$. Циклов нет. Одно ребро (например, (3, 4)): получится дерево с 5 вершинами и 4 рёбрами.
5. $O(\log n) < O(n) < O(n\log n) < O(n^2) < O(2^n)$; всех пар — $\frac{n(n-1)}{2} = O(n^2)$.

## Ответы на вопросы для самопроверки

1. $\text{IoU} = \frac{w_\cap h_\cap}{S_1 + S_2 - w_\cap h_\cap}$, где $w_\cap = \max(0, \min(x_2, x_2') - \max(x_1, x_1'))$ и аналогично $h_\cap$. При отсутствии пересечения IoU = 0 при любом расстоянии между рамками: градиента нет, и модель не знает, куда двигать рамку. GIoU добавляет штраф за площадь охватывающего прямоугольника вне объединения, DIoU — за расстояние между центрами.
2. 4-связность — соседи по сторонам, 8-связность — ещё и по диагоналям. Диагональная линия пикселей — $n$ объектов при 4-связности и 1 объект при 8-связности.
3. BFS — $O(HW)$: каждый пиксель посещается один раз, соседей — константа. Жадный NMS — $O(n^2)$ в худшем случае (плюс $O(n\log n)$ на сортировку).
4. Каждый тензор вычисляется из уже вычисленных — циклов быть не может (без явного цикла по времени, который «разворачивается»). Топологический порядок гарантирует, что при обратном проходе градиент узла полностью накоплен до того, как узел раздаст его своим родителям.
5. $5^4 = 625$ запусков; $2^{20} = 1\,048\,576$ подмножеств.
6. «Существует рамка с неположительной площадью». Проверка: `np.all((boxes[:, 2] > boxes[:, 0]) & (boxes[:, 3] > boxes[:, 1]))`.
