- как работает Naive Bayes и где в нём «наивность»? (условная независимость, уроки 13 и 40).

## 2. Интуиция

**Вероятность** — доля исходов в длинной серии одинаковых экспериментов (частотный взгляд) или степень уверенности (байесовский взгляд, урок 13). Математически оба взгляда подчиняются одним и тем же аксиомам.

**Условная вероятность** $P(A \mid B)$ — «сужаем мир до тех исходов, где случилось $B$, и смотрим, какую долю среди них занимает $A$». Это главная операция ML: модель оценивает $P(\text{класс} \mid \text{картинка})$.

**Независимость** — знание об одном событии не меняет вероятность другого. Это сильное и часто **ложное** предположение. Соседние кадры видео, снимки одного пациента, объекты одной сцены — зависимы.

## 2б. Освежение базы

**Пространство исходов** $\Omega$, **событие** $A \subseteq \Omega$ (связь с множествами урока 11).

**Аксиомы Колмогорова:** $P(A) \ge 0$; $P(\Omega) = 1$; для несовместных $A_1, A_2, \dots$ вероятность объединения равна сумме вероятностей.

**Следствия:** $P(\bar A) = 1 - P(A)$; $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ (включения-исключения).

**Классическая вероятность** (равновероятные исходы): $P(A) = |A| / |\Omega|$ — тут нужна комбинаторика.

**Условная вероятность:** $P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}$, $P(B) > 0$.

**Правило произведения:** $P(A \cap B) = P(A \mid B)\,P(B)$. Цепочкой: $P(A_1 \cap \dots \cap A_n) = P(A_1)P(A_2\mid A_1)\cdots P(A_n \mid A_1, \dots, A_{n-1})$.

**Независимость:** $P(A \cap B) = P(A)P(B)$ $\iff$ $P(A \mid B) = P(A)$.

**Формула полной вероятности:** если $B_1, \dots, B_k$ разбивают $\Omega$, то $P(A) = \sum_i P(A \mid B_i)P(B_i)$.

## 3. Математика

### 3.1. «Хотя бы одно» через дополнение

Для независимых событий с вероятностью $p$ каждое:

$$P(\text{хотя бы одно из } n) = 1 - P(\text{ни одного}) = 1 - (1 - p)^n.$$

При малом $p$ и большом $n$: $(1 - p)^n = e^{n\ln(1-p)} \approx e^{-np}$. Значит, $P \approx 1 - e^{-np}$, а **ожидаемое число** событий равно $np$. Детектор с ошибкой 0,1% на 10 000 кадрах смены даст хотя бы одну ложную тревогу почти наверняка, а в среднем 10. Поэтому в системах видеонаблюдения тревогу поднимают по нескольким подряд идущим кадрам, а не по одному.

### 3.2. Парадокс дней рождения

$n$ значений равновероятно из $N$. По правилу произведения вероятность, что все различны:

$$P(\text{все различны}) = \frac{N}{N}\cdot\frac{N - 1}{N}\cdots\frac{N - n + 1}{N} = \prod_{i=0}^{n-1}\Big(1 - \frac{i}{N}\Big) \approx e^{-\sum_i i/N} = e^{-n(n-1)/(2N)}.$$

Совпадение становится вероятным при $n \approx \sqrt{N}$, а не при $n \approx N$. Пар $\binom{n}{2} \approx n^2/2$, и каждая может совпасть. Для 32-битных хэшей ($N \approx 4{,}3 \cdot 10^9$) коллизии ожидаемы уже на ~$10^5$ кадрах. Значит, для дедупликации больших датасетов нужны хэши длиннее, или совпадения хэша нужно проверять.

### 3.3. Условная вероятность и формула полной вероятности

Формула полной вероятности — «взвешенное среднее условных вероятностей». Из неё следует важный эффект для метрик: **общая точность модели зависит от состава данных**. Если в продакшене доля ночных кадров вырастет с 30% до 60%, точность упадёт, хотя модель не изменилась:

$$P(\text{верно}) = P(\text{верно}\mid\text{ночь})\,P(\text{ночь}) + P(\text{верно}\mid\text{день})\,P(\text{день}).$$

Это формальная сторона «сдвига распределения» из урока 1. Отсюда же практическое правило: метрики нужно смотреть **по срезам** (день/ночь, мелкие/крупные объекты), а не только общую.

### 3.4. Условная независимость

$A$ и $B$ условно независимы при данном $C$, если $P(A \cap B \mid C) = P(A\mid C)\,P(B \mid C)$.

Это **не то же самое**, что обычная независимость, и ни одна из них не следует из другой. Пример: «мокрый асфальт» и «люди с зонтами» зависимы (оба чаще бывают вместе), но условно независимы при известном «идёт дождь». Наивный Байес (уроки 13, 40) предполагает, что признаки условно независимы при известном классе. Обычно это неправда, но классификатор часто работает всё равно.

### 3.5. Зависимость в данных и утечка

Если val-кадр выбирается независимо с вероятностью $q = 0{,}2$, то вероятность, что **все** его 4 ближайших соседа по видео тоже попали в val, равна $q^4 = 0{,}0016$. С вероятностью 0,998 почти-копия val-кадра лежит в train, и модель «видела» его. Метрика на такой валидации измеряет запоминание, а не обобщение. Лечение — разбиение **по группам** (по видео, сцене, пациенту): `GroupKFold` в уроке 61.

## 4. Реализация с нуля

Файл: [код/probability.py](код/probability.py) сравнивает точные формулы с симуляцией Монте-Карло:

```python
def birthday_exact(n, N):
    return 1 - prod((N - i) / N for i in range(n))

def birthday_mc(n, N, trials=20_000):
    draws = rng.integers(0, N, size=(trials, n))
    s = np.sort(draws, axis=1)
    return float(np.mean(np.any(s[:, 1:] == s[:, :-1], axis=1)))

def at_least_one(p, n):
    return 1 - (1 - p) ** n
```

Проверка на совпадения в `birthday_mc` векторизована через сортировку: после неё одинаковые значения стоят рядом (приём $O(n\log n)$ из урока 11).

```

дни рождения, n=50: точно 0.9704, Монте-Карло 0.9683
хэши 32 бита, 100 000 кадров: P(коллизия) = 0.688
P(хотя бы одно ложное срабатывание за смену): формула 0.99995, симуляция 1.00000
ожидаемое число ложных срабатываний: 10
n=    100: средняя |ошибка| частоты 0.04050, теория 0.03656
n=   1000: средняя |ошибка| частоты 0.01154, теория 0.01156
n=  10000: средняя |ошибка| частоты 0.00367, теория 0.00366
n= 100000: средняя |ошибка| частоты 0.00133, теория 0.00116
```

**Закон больших чисел:** частота сходится к вероятности, а ошибка убывает как $1/\sqrt{n}$. Чтобы уменьшить ошибку в 10 раз, нужно в **100** раз больше данных. Теоретическая формула $\sqrt{p(1-p)/n}\cdot\sqrt{2/\pi}$ выведется в уроках 14–15. Отсюда практический вывод для оценки моделей: точность, посчитанная на 100 тестовых картинках, имеет погрешность ≈ ±4–5 процентных пунктов. Разница «87% против 89%» на таком тесте ничего не значит (урок 18).

**Условные вероятности по таблице результатов детектора** (синтетика: ночью и на мелких объектах хуже):


`groupby(...).mean()` по булевому столбцу — это и есть условная вероятность. Общие 79% скрывают провал на ночных мелких объектах (54%). Формула полной вероятности сходится с прямым подсчётом. «Ночь» и «мелкий объект» здесь сгенерированы независимыми, и $P(A \cap B) \approx P(A)P(B)$ подтверждается в пределах случайной погрешности.

## 6. Типичные ошибки и как их отлаживать

| Ошибка | Пример | Как правильно |
|---|---|---|
| Путают $P(A \mid B)$ и $P(B \mid A)$ | «90% ночных кадров — ошибки» ≠ «90% ошибок — ночью» | Явно писать, что дано и что ищем; урок 13 (Байес) связывает одно с другим |
| Перемножают вероятности зависимых событий | $P(\text{ошибка на кадре 1 и на кадре 2}) = p^2$ для соседних кадров — сильно занижено | Проверять независимость; соседние кадры ошибаются «пачками» |
| Независимость против несовместности | «Ночь» и «день» несовместны, а значит **зависимы**: знание «ночь» обнуляет вероятность «дня» | Несовместные события с $P > 0$ всегда зависимы |
| Случайное разбиение коррелированных данных | Завышенные метрики | Разбиение по группам (видео, сцена, пациент) |
| Одна общая метрика | Провал на важном срезе незаметен | Метрики по срезам; формула полной вероятности — как они складываются |
| Оценка вероятности по малой выборке | «3 из 3 — модель идеальна» | Помнить про погрешность $\sim 1/\sqrt n$; доверительные интервалы (урок 18) |

## Ответы на диагностику

1. $6/36 = 1/6$; $1 - (5/6)^2 = 11/36$; $P(\text{вторая} = 4) = 1/6$.
2. $P(A \cup B) = 0{,}4 + 0{,}5 - 0{,}2 = 0{,}7$; $P(A \mid B) = 0{,}2/0{,}5 = 0{,}4 = P(A)$ — независимы.
3. $1 - 0{,}99^{100} \approx 0{,}634$.
4. $0{,}02 \cdot 0{,}7 + 0{,}05 \cdot 0{,}3 = 0{,}029$ — 2,9%.
5. Независимость: $P(A \cap B) = P(A)P(B)$, знание одного не меняет вероятность другого. Несовместность: $A \cap B = \varnothing$. Несовместные с $P > 0$ всегда **зависимы**: $P(A \cap B) = 0 \neq P(A)P(B)$.

## Ответы на вопросы для самопроверки

1. $P(A\mid B) = P(A\cap B)/P(B)$ — доля $A$ среди исходов, где случилось $B$. В pandas: `df[df.B].A.mean()` или `df.groupby("B").A.mean()` для булевых столбцов.
2. $P(A) = \sum_i P(A\mid B_i)P(B_i)$. Общая точность — среднее точностей по срезам с весами долей срезов. Если веса (состав данных) меняются, общая точность меняется даже при неизменной модели.
3. Независимость — $P(A\cap B) = P(A)P(B)$; несовместность — $A \cap B = \varnothing$. Условная независимость — независимость внутри каждого «мира» с фиксированным $C$; она не следует из обычной и не влечёт её.
4. $1 - (1-p)^n$ (через дополнение «ни одного»); ожидание $np$ (сумма индикаторов, урок 14).
5. Число пар растёт как $n^2/2$, и каждая совпадает с вероятностью $1/N$. Ожидаемое число совпадений $\approx n^2/(2N)$ становится порядка 1 при $n \approx \sqrt{2N}$.
6. Почти-копия val-кадра остаётся в train, если хотя бы один из 4 соседей не попал в val: $1 - 0{,}2^4 = 0{,}9984$. Модель оценивается на данных, которые фактически видела.
7. Погрешность ≈ $\sqrt{p(1-p)/n}$. Для $p \approx 0{,}9$ и погрешности 0,01: $n \approx 0{,}09/0{,}0001 = 900$ примеров; для «±1 п.п. с 95% уверенностью» (≈ 2 стандартных отклонения) — ≈ 3600.
