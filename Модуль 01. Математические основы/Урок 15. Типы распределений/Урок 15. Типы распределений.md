## 1. Зачем это нужно

- Почему для регрессии рамок берут L1/Smooth L1, а не MSE? Почему классификация — кросс-энтропия, а не MSE по вероятностям? Почему для подсчёта объектов (crowd counting) иногда берут Poisson loss?
- Что такое KL в функции потерь VAE (урок 86) и в дистилляции моделей?
- Как найти аномальные кадры по эмбеддингам? (многомерная нормаль, расстояние Махаланобиса)
- Почему всё «приблизительно нормально»? (центральная предельная теорема)

## 2. Интуиция

**Распределение — модель того, как порождаются данные.** Монетка (верно/неверно) — Бернулли. Класс объекта — категориальное. Число ошибок из $n$ проверок — биномиальное. Число объектов на кадре или событий за минуту — Пуассона. Сумма многих мелких независимых влияний (шум сенсора, ошибка разметчика в пикселях) — нормальное.

**MLE — «подбери параметры так, чтобы увиденные данные были максимально вероятны».** Если модель говорит «$y$ = предсказание + гауссов шум», то максимизация вероятности данных совпадает с минимизацией суммы квадратов ошибок.

**Энтропия** — средняя «неожиданность» исхода, или сколько бит в среднем нужно, чтобы закодировать исход. **Кросс-энтропия** $H(p, q)$ — сколько бит уйдёт, если данные приходят из $p$, а код построен под $q$. **KL-дивергенция** — перерасход бит из-за того, что мы думаем «$q$», а на самом деле «$p$». Это мера несовпадения распределений, но не расстояние: она несимметрична.

## 3. Математика

### 3.1. Зоопарк распределений и их место в ML

| Распределение | PMF / PDF | Среднее, дисперсия | Где в ML/CV |
|---|---|---|---|
| Бернулли$(p)$ | $p^y(1-p)^{1-y}$ | $p$, $p(1-p)$ | Бинарная классификация, «объект есть/нет», objectness в YOLO |
| Категориальное$(\pi)$ | $\prod_k\pi_k^{[y=k]}$ | | Многоклассовая классификация, выход softmax |
| Биномиальное$(n, p)$ | $\binom{n}{k}p^k(1-p)^{n-k}$ | $np$, $np(1-p)$ | Число верных из $n$ проверок, accuracy на тесте |
| Пуассона$(\lambda)$ | $\frac{\lambda^ke^{-\lambda}}{k!}$ | $\lambda$, $\lambda$ | Число объектов на кадре, фотонный шум сенсора |
| Равномерное$(a, b)$ | $\frac{1}{b-a}$ | $\frac{a+b}{2}$, $\frac{(b-a)^2}{12}$ | Случайные аугментации, инициализация весов |
| Нормальное$(\mu, \sigma^2)$ | $\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$, $\sigma^2$ | Шум, инициализация, MSE, VAE |
| Лапласа$(\mu, b)$ | $\frac{1}{2b}e^{-|x-\mu|/b}$ | $\mu$, $2b^2$ | MAE/L1-потеря, Lasso (урок 13) |
| Экспоненциальное$(\lambda)$ | $\lambda e^{-\lambda x}$ | $1/\lambda$, $1/\lambda^2$ | Время до события |
| Beta$(a, b)$ | урок 13 | $\frac{a}{a+b}$ | Prior для вероятностей, Mixup |
| Многомерное нормальное | 3.5 | $\mu$, $\Sigma$ | GMM (урок 47), аномалии, VAE |

**Пуассон как предел биномиального:** $n \to \infty$, $p \to 0$, $np = \lambda$. Миллион пикселей, у каждого крошечная вероятность «быть объектом», и в итоге число объектов распределено по Пуассону.

### 3.2. Центральная предельная теорема (ЦПТ)

Если $X_1, \dots, X_n$ независимы, одинаково распределены, имеют среднее $\mu$ и дисперсию $\sigma^2 < \infty$, то

$$\frac{\bar X - \mu}{\sigma/\sqrt n} \xrightarrow{d} \mathcal{N}(0, 1).$$

Сумма многих независимых мелких влияний — нормальна, **независимо от их собственного распределения**. Поэтому нормальным считают шум измерений. И поэтому для доверительных интервалов метрик (урок 18) работает нормальное приближение: accuracy — это среднее индикаторов «верно/неверно».

### 3.3. MLE: откуда берутся функции потерь

Для независимых наблюдений правдоподобие — произведение, а его логарифм — сумма:

$$\hat\theta = \arg\max_\theta\prod_i p(y_i\mid x_i, \theta) = \arg\min_\theta\Big[-\sum_i\log p(y_i\mid x_i,\theta)\Big] \quad\text{(NLL — negative log-likelihood).}$$

**(а) Гауссов шум → MSE.** Модель: $y_i \sim \mathcal{N}(f_\theta(x_i), \sigma^2)$.

$$-\log p(y_i \mid x_i) = \frac12\log(2\pi\sigma^2) + \frac{(y_i - f_\theta(x_i))^2}{2\sigma^2}.$$

При фиксированной $\sigma$ первое слагаемое — константа. Значит, $\arg\min_\theta\text{NLL} = \arg\min_\theta\sum_i(y_i - f_\theta(x_i))^2$. **MSE — это MLE при гауссовом шуме.**

Заодно MLE самих параметров нормального распределения: $\partial_\mu\text{NLL} = -\sum(y_i - \mu)/\sigma^2 = 0 \Rightarrow \hat\mu = \bar y$; $\partial_\sigma\text{NLL} = n/\sigma - \sum(y_i - \mu)^2/\sigma^3 = 0 \Rightarrow \hat\sigma^2 = \frac1n\sum(y_i - \bar y)^2$ (смещённая оценка, деление на $n$).

**(б) Шум Лапласа → MAE (L1).** $-\log p = \log 2b + |y - f|/b$. Минимизация $\sum|y_i - f(x_i)|$. Хвосты у Лапласа тяжелее, выбросы для него «не так невероятны», поэтому L1 **устойчивее к выбросам**. Ошибка разметчика на 50 пикселей в одной рамке испортит MSE-обучение сильнее, чем L1. Отсюда Smooth L1 в Faster R-CNN: L2 возле нуля (гладко), L1 вдали (устойчиво).

**(в) Бернулли → бинарная кросс-энтропия (BCE).** $p(y\mid x) = p^y(1-p)^{1-y}$, $p = \sigma(f(x))$:

$$-\log p(y\mid x) = -\big[y\log p + (1-y)\log(1-p)\big].$$

**(г) Категориальное → кросс-энтропия (CE).** $p(y\mid x) = \operatorname{softmax}(z)_y$, $-\log p = -\log\operatorname{softmax}(z)_y$. Градиент по логитам — $p - y$ (урок 10).

**(д) Пуассон → Poisson loss.** $-\log p(k\mid\lambda) = \lambda - k\log\lambda + \log k!$. Для подсчёта объектов, где дисперсия растёт со средним.

**Почему не MSE для классификации?** MSE соответствует гауссову шуму на вероятностях — бессмысленная модель для меток 0/1. Вдобавок градиент MSE через сигмоиду содержит множитель $\sigma'(z) \le 0{,}25$, который затухает при уверенной ошибке. У CE этот множитель сокращается, и градиент $p - y$ остаётся большим, когда модель уверенно ошибается.

### 3.4. Энтропия, кросс-энтропия, KL

Для дискретных распределений:

$$H(p) = -\sum_k p_k\log p_k, \quad H(p, q) = -\sum_k p_k\log q_k, \quad \text{KL}(p\,\|\,q) = \sum_k p_k\log\frac{p_k}{q_k} = H(p, q) - H(p).$$

**$\text{KL} \ge 0$ (неравенство Гиббса).** $-\text{KL}(p\|q) = \sum p_k\log\frac{q_k}{p_k} \le \log\sum p_k\frac{q_k}{p_k} = \log\sum q_k = \log 1 = 0$. Неравенство — это Йенсен для вогнутого логарифма (урок 14). Равенство — только при $p = q$.

**Максимум энтропии** на $K$ исходах — у равномерного распределения: $H = \log K$. Это следует из $\text{KL}(p\,\|\,\text{uniform}) = \log K - H(p) \ge 0$.

**Главное:** при обучении классификатора $p$ — истинное распределение (one-hot метка), $q$ — предсказание модели. $H(p)$ от модели не зависит, поэтому

$$\min_\theta H(p, q_\theta) \iff \min_\theta\text{KL}(p\,\|\,q_\theta) \iff \text{MLE}.$$

Кросс-энтропия, KL и максимальное правдоподобие — **одна и та же задача**, записанная по-разному.

**Label smoothing:** вместо one-hot $p = (0, 1, 0)$ берут $(\varepsilon/K, 1 - \varepsilon + \varepsilon/K, \varepsilon/K)$. Модель перестаёт гнать логиты в бесконечность, становится лучше откалибрована и меньше переобучается на ошибки разметки.

**KL несимметрична.** $\text{KL}(p\|q)$ сильно штрафует места, где $p > 0$, а $q \approx 0$ («не пропусти ничего из $p$»). $\text{KL}(q\|p)$ — наоборот. Это важно в VAE и дистилляции.

**KL двух гауссиан** (понадобится в VAE):

$$\text{KL}\big(\mathcal{N}(\mu_1, \sigma_1^2)\,\|\,\mathcal{N}(\mu_2, \sigma_2^2)\big) = \log\frac{\sigma_2}{\sigma_1} + \frac{\sigma_1^2 + (\mu_1 - \mu_2)^2}{2\sigma_2^2} - \frac12.$$

### 3.5. Многомерное нормальное распределение

$$\mathcal{N}(x;\mu,\Sigma) = \frac{1}{(2\pi)^{d/2}|\Sigma|^{1/2}}\exp\Big(-\tfrac12(x - \mu)^\top\Sigma^{-1}(x - \mu)\Big).$$

- $(x - \mu)^\top\Sigma^{-1}(x - \mu)$ — квадрат **расстояния Махаланобиса**: евклидово расстояние после whitening (урок 14). Линии уровня плотности — эллипсоиды с осями вдоль собственных векторов $\Sigma$ и полуосями $\propto\sqrt{\lambda_i}$ (урок 6).
- $|\Sigma|$ — определитель, «объём» облака (урок 5).
- **Вычисляют через Холецкого** $\Sigma = LL^\top$. Тогда $\log|\Sigma| = 2\sum\log L_{ii}$, а квадратичная форма — $\|L^{-1}(x - \mu)\|^2$. Ни обратной матрицы, ни определителя явно — так устойчивее (урок 5).
- **Детекция аномалий:** подгоняем $\mu$, $\Sigma$ по эмбеддингам нормальных кадров (MLE — выборочные среднее и ковариация). Кадр с большим расстоянием Махаланобиса — аномалия. Так работает, например, метод PaDiM для поиска дефектов.

## 4. Реализация с нуля

Файл: [код/distributions.py](код/distributions.py). Ключевые функции:

```python
def cross_entropy_logits(logits, labels):
    z = logits - logits.max(axis=1, keepdims=True)
    log_probs = z - np.log(np.exp(z).sum(axis=1, keepdims=True))
    return float(-np.mean(log_probs[np.arange(len(labels)), labels]))

def kl_gauss(mu1, s1, mu2, s2):
    return float(np.log(s2 / s1) + (s1**2 + (mu1 - mu2) ** 2) / (2 * s2**2) - 0.5)

def mvn_logpdf(x, mu, Sigma):
    d = mu.size
    L = np.linalg.cholesky(Sigma)                        # Σ = L L^T
    z = np.linalg.solve(L, (x - mu).T)                   # z = L^{-1}(x - mu); ||z||² = расстояние Махаланобиса²
    log_det = 2 * np.sum(np.log(np.diag(L)))
    return -0.5 * (d * np.log(2 * np.pi) + log_det + np.sum(z**2, axis=0))
```

В `cross_entropy_logits` — **log-sum-exp трюк**: $\log\sum e^{z_k} = m + \log\sum e^{z_k - m}$, где $m = \max z$. Без него логит 1000 даст `inf`. Тест `test_ce_stable_for_huge_logits` проверяет именно это.

Каждая строка подтверждает утверждение раздела 3:
- MLE нормального совпадает с `scipy.stats.norm.fit`;
- гауссово NLL — это MSE с точностью до множителя и константы;

## 5. Библиотеки

- `scipy.stats.<dist>.fit(data)` — MLE параметров любого распределения.
- `scipy.stats.entropy(p)` и `scipy.stats.entropy(p, q)` — энтропия и KL. Внимание: функция сама нормирует аргументы.
- PyTorch: `nn.CrossEntropyLoss` (принимает **логиты**, внутри log-softmax), `nn.BCEWithLogitsLoss` (логиты, внутри устойчивая сигмоида), `nn.KLDivLoss` (ждёт **логарифмы** вероятностей первым аргументом — частая ловушка), `nn.PoissonNLLLoss`, `nn.SmoothL1Loss`, `torch.distributions` (сэмплы, `log_prob`, KL между распределениями).

## 6. Типичные ошибки и как их отлаживать

| Ошибка | Последствие | Как правильно |
|---|---|---|
| Softmax перед `nn.CrossEntropyLoss` | Двойной softmax: обучение медленное, градиенты маленькие | Подавать логиты |
| `torch.log(torch.softmax(z))` вручную | `-inf` и NaN при уверенных предсказаниях | `log_softmax` / `CrossEntropyLoss` |
| `nn.KLDivLoss(p, q)` с вероятностями | Неверное значение (функция ждёт `log q` первым аргументом) | Читать документацию; проверять на $p = q$ (должен быть 0) |
| MSE для классификации | Медленное обучение, затухающий градиент при уверенной ошибке | CE / BCE |
| MSE для регрессии рамок с шумной разметкой | Выбросы доминируют в градиенте | L1 / Smooth L1 / IoU-потери |
| Плотность многомерной нормали через `inv` и `det` | Переполнение и неустойчивость в высоких размерностях | Холецкий, `logpdf`, работа в логарифмах |
| `np.std` как оценка σ для маленьких выборок | Смещение вниз (деление на $n$) | `ddof=1`, если нужна несмещённая дисперсия |

## Ответы на вопросы для самопроверки

1. Биномиальное (сумма 200 Бернулли); категориальное (один из $K$ классов); Пуассона (счётное число редких событий в «области»); нормальное (сумма многих мелких независимых влияний — ЦПТ; при очень малой освещённости — Пуассона).
2. $-\log\mathcal{N}(y; f, \sigma^2) = \text{const} + (y - f)^2/(2\sigma^2)$, сумма по объектам — MSE с точностью до множителя. MAE — шум Лапласа. У Лапласа хвосты тяжелее, поэтому выброс «вероятнее», а штраф растёт линейно, а не квадратично: градиент от выброса ограничен.
3. $-\log[p^y(1-p)^{1-y}] = -y\log p - (1-y)\log(1-p)$. MSE предполагает гауссов шум на метках 0/1, что бессмысленно. Через сигмоиду её градиент содержит $\sigma'(z)$ и затухает при уверенной ошибке, а у CE градиент $p - y$.
4. $H(p) = -\sum p\log p$; $H(p,q) = -\sum p\log q$; $\text{KL} = \sum p\log(p/q) = H(p,q) - H(p)$. $-\text{KL} = \sum p\log(q/p) \le \log\sum q = 0$ по Йенсену.
5. $H(p, q_\theta) = H(p) + \text{KL}(p\|q_\theta)$, где $H(p)$ не зависит от $\theta$. А $H(\hat p_{\text{data}}, q_\theta) = -\frac1n\sum\log q_\theta(y_i\mid x_i)$ — это средний NLL, который минимизирует MLE.
6. $d_M(x) = \sqrt{(x-\mu)^\top\Sigma^{-1}(x-\mu)}$ — расстояние с учётом масштабов и корреляций признаков (евклидово после whitening). Подгоняем $\mu$, $\Sigma$ по эмбеддингам нормальных кадров. Кадры с большим $d_M$ (например, выше 99-го перцентиля на валидации) помечаем как аномалии.
7. Нормированное среднее $n$ независимых одинаково распределённых величин с конечной дисперсией сходится к $\mathcal{N}(0,1)$. Accuracy — среднее индикаторов «верно», поэтому $\widehat{\text{acc}} \approx \mathcal{N}\big(\text{acc}, \text{acc}(1-\text{acc})/n\big)$, и интервал — $\widehat{\text{acc}} \pm 1{,}96\sqrt{\widehat{\text{acc}}(1-\widehat{\text{acc}})/n}$.
