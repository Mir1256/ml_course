Решения клади в папку [решения/](решения/) рядом с этим файлом и пиши «проверь урок 17».

**🟢 Базовое — «Исправь плохие графики»** (`fix_charts.py` + картинки «до/после»)
Построй по данным `make_annotations()` три намеренно плохих графика и их исправленные версии:
1. Круговая диаграмма долей 6 классов → отсортированные столбцы с подписями процентов.
2. Столбцы «средняя уверенность днём и ночью» с осью Y от 0,55 → ось от 0, плюс интервал ±2 стандартные ошибки (урок 14: $\sigma/\sqrt n$).
3. Тепловая карта центров в палитре `jet` → `viridis` с подписанной цветовой шкалой.
Под каждой парой в комментарии — одно предложение: чем плох исходный график.

**🟡 Среднее — «Выбор ширины ядра»** (`bandwidth.py` + `bandwidth.png`)
1. Сгенерируй смесь двух нормальных (например, log-площади «мелких» и «крупных» объектов: $\mathcal{N}(2{,}5;\ 0{,}3^2)$ и $\mathcal{N}(4;\ 0{,}5^2)$, доли 0,3/0,7), n = 300.
2. Построй KDE при $h \in \{0{,}02;\ 0{,}1;\ h_{\text{Скотта}};\ 1{,}0\}$ поверх истинной плотности. При каком $h$ пропадает бимодальность?
3. Выбери $h$ **кросс-валидацией по правдоподобию**: для каждого $h$ считай $\sum_i\log\hat f_{-i}(x_i)$, где $\hat f_{-i}$ — KDE без точки $i$ (leave-one-out, урок 62). Векторизуй через матрицу попарных ядер с обнулённой диагональю.
4. Сравни найденный $h$ с правилами Скотта и Сильвермана. Почему правила «эталонного нормального» на бимодальных данных сглаживают слишком сильно?

**🔴 Со звёздочкой — «Дашборд анализа ошибок детектора»** (`error_dashboard.py` + `error_dashboard.png`)
Собери одну фигуру 2×3 через `plt.subplot_mosaic` по данным урока 16. Каждый график отвечает на вопрос в своём заголовке:
1. Где модель менее уверена: по классам × день/ночь (тепловая карта средних с подписями в ячейках).
2. Как уверенность зависит от размера: скользящая медиана уверенности по log(площади) с полосой IQR.
3. Сколько рамок теряется при разных порогах уверенности: кривая «порог → доля оставленных рамок» по срезам.
4. Карта центров только для рамок с низкой уверенностью против всех (нормированная разность).
5. Распределение aspect для двух групп уверенности (ECDF).
6. Текстовая панель с 3 главными выводами (`ax.text`).
Требования: единый стиль, подписи осей с единицами, не больше двух цветов на график, фигура читается при печати в оттенках серого.
