Решения клади в папку [решения/](решения/) рядом с этим файлом и пиши «проверь урок 16».

**🟢 Базовое — «Аудит невозможных значений»** (`audit.py` + `test_audit.py`)
На данных `make_annotations()` из урока:
1. Напиши `find_impossible(df, img_w=640, img_h=480)`, возвращающую таблицу проблем: рамка выходит за кадр, нулевая или отрицательная площадь, площадь больше кадра, соотношение сторон > 20 или < 1/20. У каждой строки — тип проблемы.
2. Сколько проблемных рамок нашлось и какая доля от внесённых 0,5% ошибок поймана?
3. Тесты: на вручную составленном DataFrame из 6 рамок функция находит ровно ожидаемые проблемы.

**🟡 Среднее — «EDA-отчёт по классам»** (`class_report.py` + `class_report.md`)
1. Для каждого класса посчитай: число рамок, долю изображений, где класс встречается, медиану и IQR площади, долю small/medium/large по определению COCO (< 32², 32²–96², > 96²), медиану aspect, среднюю уверенность модели днём и ночью.
2. Найди 3 комбинации «класс × размер × день/ночь» с самой низкой средней уверенностью.
3. Напиши `class_report.md` из 5–7 выводов в формате «наблюдение → что это значит для обучения детектора» (например: «76% светофоров мельче 32×32 → нужен вход большего разрешения или тайлинг»).

**🔴 Со звёздочкой — «Робастность на практике»** (`robustness.py` + график)
1. Возьми чистую нормальную выборку (n = 1000). Постепенно заменяй долю $\varepsilon \in [0; 0{,}5]$ точек на выбросы (значение 1000). Для каждой $\varepsilon$ посчитай: среднее, медиану, усечённое среднее (10%), std, IQR/1,349, $1{,}4826\cdot$MAD.
2. Нарисуй «кривые разрушения» и найди численно точку разрушения каждой статистики. Сравни с теорией из раздела 3.2.
3. Объясни, почему $\text{IQR}/1{,}349$ — оценка $\sigma$ для нормальных данных (выведи 1,349 через `scipy.stats.norm.ppf`).
4. Вывод для практики: какие статистики использовать для нормализации признаков, если в данных есть ошибки разметки? (Подсказка: `sklearn.preprocessing.RobustScaler`.)
